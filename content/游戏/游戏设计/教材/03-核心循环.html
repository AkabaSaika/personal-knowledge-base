第 3 章 · 核心循环：为什么想「再来一局」

「就玩十分钟」为什么总是变成凌晨两点？这不是意志力的问题——是有人精心焊好了一个环：每当你想停下，下一个奖励刚好探出头。这一章把这个环拆开：它由什么组成、靠什么转动、为什么会越转越大，以及——它在什么地方会断掉。学会看循环，你就拿到了诊断「玩不下去了」的听诊器。

🎯 学习目标

学完本章你能：① 画出任何游戏的核心循环图；② 解释奖励与成长如何把小环滚成飞轮；③ 识别秒、分钟、小时三层循环各自负责什么；④ 用「毕业 / 卡关 / 重复」三种断裂模式，诊断一个游戏为什么被弃坑。

最小的环：行动与反馈

上一章的 MDA 是一张静止的解剖图，但游戏是转动的。转动的最小单元，是一个首尾相接的环：你做一个动作，世界给一个结果，结果产生一个新局面，新局面又召唤下一个动作。看俄罗斯方块的一秒钟：

这个环里被重复得最多的那个动作，叫核心动词——马里奥是「跳」，俄罗斯方块是「放」，射击游戏是「瞄与射」。核心循环的手感，几乎决定了游戏的生死：玩家的一辈子，就是把你的核心循环重复几千几万遍。环本身不好玩，奖励堆再多也救不回来（本章结尾的「重复断裂」会回到这一点）。

奖励让环转起来，成长让环变大

光有环还不够，环需要燃料。燃料就是奖励，它分两种，性格完全不同：

  • 即时快感型：消行的闪光、暴击跳出的数字、金币的叮当声——当下爽一下，不留痕迹；
  • 积累成长型：经验、金币、装备、解锁——它们会回头改变行动本身：斧头升级了，同样是砍一下，产出翻倍。

成长型奖励让环不再是原地打转的圆，而是一条向上的螺旋：行动产出资源 → 资源换成长 → 成长放大下一轮行动。这个「飞轮」转起来是什么感觉？下面这个只有两个按钮的小游戏让你亲手体验——请重点观察右侧曲线在每次升级瞬间的变化。

💡 两个极端实验

① 把系数调到 1.1：你会连点几下就买光好几级——爽是爽，但目标像纸糊的，几十秒后你就没有想要的东西了。环断于「毕业」。② 调到 3.0：下一级的价格涨得比你的产出快得多，越砍越觉得遥遥无期。环断于「卡关」。③ 回到 1.8 附近：每次升级都感觉「再攒一小会儿就够了」——这条不断后退却总够得着的胡萝卜，就是「上头」的数学结构。循环好不好玩，一半在结构，一半在节奏；节奏由数值控制——这正是第 9 章数值设计的主题。

三层时间尺度：秒、分钟、小时

成熟的游戏不止一个环，而是一套互相咬合的环，按时间尺度分层。用 Roguelike 名作《以撒的结合》看这套齿轮怎么咬合：

三层各司其职：秒级环负责「现在好不好玩」（手感与即时反馈）；分钟级环负责「这一局值不值」（阶段目标与结算）；小时级环负责「明天还来不来」（成长、收集、解锁）。手游把这套分层用到了极致——原神的战斗连招是秒级环，每日委托和体力副本是分钟级环，版本更新与角色养成是横跨数月的小时级环。诊断一个游戏，先分层再看环：很多「说不上哪不对」的游戏，问题是某一层是空的——比如秒级操作很爽但没有长期目标（留不住人），或者长线养成很深但操作无聊（第一小时就劝退）。

环从哪里断：毕业、卡关与重复

玩家弃坑，几乎总能在循环上找到断口。三种断法，症状与病灶各不相同：

断裂模式断在哪一环玩家的原话典型场景
毕业 奖励失去意义——没有想要的东西了 「装备毕业了，突然不知道上线干嘛。」 MMO 版本末期的毕业潮；收集类游戏图鉴集满
卡关 成长停滞——付出不再换来前进 「这关打了三十次了，数值差太多，练度不够。」 数值墙劝退；手游长草期「每天上线也没变强」
重复 行动本身乏味——奖励再多也提不起手 「一想到还要再刷五十遍这个本，就不想登录。」 刷子游戏的疲劳；日常任务变成打卡上班

注意三种断裂对应循环的三个部件：毕业断在奖励，卡关断在成长，重复断在行动。这个对应关系让诊断变成流水线作业：听玩家抱怨 → 定位断的部件 → 对症开方。也要说破一个残酷事实：所有循环终会断裂，设计师做的是让它晚一点断、断得体面一点——让玩家带着好感离开，而不是带着怨气。

学会画循环图

循环图是本章交给你的手艺，画法只有三条约定：圆角框写行动或资源；实线箭头写转化（谁变成谁）；虚线箭头写跨局或受限的转化（如每日上限、体力闸门）。看一张完整示例——《吸血鬼幸存者》的双层循环：

画循环图的价值在于「一眼看出问题」：哪个框只进不出（囤积无用的资源）、哪条箭头没有回流（付出不改变任何东西）、哪一层整个是空的。下一章它会作为「设计师五问」的第二问，进入你的随身拆解模板。

例题

📘 例 1 · 马里奥的循环：几乎没有成长，为什么百玩不厌

画出超级马里奥单关的循环，并回答：它的跨局成长几乎为零（只有命数），为什么仍让人反复重玩？

分析：单关循环——跑与跳（行动）→ 越过障碍、吃到金币道具（结果）→ 推进到更难的地形（新局面）→ 旗杆结算。跨局层面：没有经验、没有装备，死了从头再来。它靠什么留人？靠行动本身的质量：跳跃的手感、每一段地形的新编排，让「重复第一百次跳跃」依然有滋味。这引出循环的两大流派——执行乐趣型（环的乐趣在动作本身：马里奥、俄罗斯方块、音游）与成长乐趣型（环的乐趣在变强：MMO、放置游戏）。结论：好游戏至少占一头；两头都不占的游戏，靠营销拉来多少人就流失多少人。也存在两头都占的（以撒：操作有味道，跨局有解锁）——那是留存曲线最漂亮的一类。

📘 例 2 · 原神的树脂：被骂最多的设计，为什么不删

原神的「树脂」（体力）限制每天能刷的副本次数，玩家骂声不断，官方多年不撤。用循环与闸门的语言完整分析这个设计。

分析：先画环——每日环：上线 → 花树脂刷副本 → 拿养成材料 → 角色变强 → （树脂耗尽，今日环停转）→ 明天再来。树脂是画在「刷副本」箭头上的虚线闸门：它不改变转化方向，只限制转化速率。闸门的三重作用：① 对玩家——防止一天肝完一个月的内容后迅速毕业（回看断裂模式：闸门用「限流」推迟毕业）；② 对习惯——「树脂不清空就亏了」制造每日回归的钩子，把小时级环切成三百六十五个每日环；③ 对商业——追进度的玩家可以花钱买树脂，闸门本身就是收费点。代价同样清楚：它把「玩」变成了「上班打卡」，重复断裂的风险升高，也是口碑上最大的失分项。结论：树脂是「商业诉求写进循环」的教科书案例——设计上它不优雅，但在「延长寿命、养成习惯、创造收入」三项上同时得分，所以骂声再大也不会删。看懂闸门，你就看懂了免费手游一半的设计决策。

📘 例 3 · 吸血鬼幸存者：把环的转速拉到极限

吸血鬼幸存者为什么公认「十分钟就上头」？从奖励密度的角度分析。

分析：数一数它一局里奖励事件的频率——怪物掉的经验宝石几乎铺满地面（秒级：持续的收集反馈）；平均每十几秒升一级，弹出一次「三选一」（分钟级压缩到了秒级：高频决策点）；每隔几分钟刷精英怪掉宝箱（节奏峰值）。对比传统 RPG 半小时升一级、一小时换一件装备——吸血鬼幸存者把奖励密度拉高了两个数量级，等于把大环压扁塞进小环的转速里。结论：环的转速本身就是设计变量。转速快 = 上头快，但也烧得快（内容消耗快、疲劳来得早）——该作一局固定 30 分钟强制结算，正是给这台超速引擎装的刹车。「多快给一次奖励」没有标准答案，但必须是被选择过的，而不是随缘的。

习题

✏️ 习题 3.1 基础

用「行动 → 结果 → 新局面」画出（或用箭头写出）俄罗斯方块的秒级循环，并标出其中的奖励属于即时快感型还是积累成长型。

查看答案与解析

答案：放下一块（行动）→ 消行得分 / 堆高一层（结果）→ 场地更空 / 更挤，且速度渐增（新局面）→ 放下一块……奖励几乎全部是即时快感型（消行闪光、得分），唯一近似「成长」的是速度上升——但它长在游戏身上而不是玩家身上，是难度成长而非能力成长。

解析：「成长长在谁身上」是个好用的追问：俄罗斯方块里数值上变强的是游戏（更快），变强的玩家能力全在你自己的手和脑里——这正是执行乐趣型游戏的特征：它把成长放在玩家的技能里，而不是存档文件里。删档对马里奥玩家几乎无损，对 MMO 玩家是灭顶之灾，差别就在这。

✏️ 习题 3.2 基础

糖豆人一局由多轮小关组成。分别写出「一关」和「一局」两层循环各是什么，各自的奖励是什么。

查看答案与解析

答案：一关（分钟级）：起跑 → 闯过障碍 / 被淘汰 → 晋级名单公布 → 下一关。奖励：晋级的如释重负 + 翻车的笑料。一局（十几分钟）：连续过关 → 决赛 → 夺冠或出局 → 结算皮肤货币 → 再来一局。奖励：夺冠的稀有荣耀 + 可积累的皮肤解锁。

解析：注意两层奖励的分工：关卡层的奖励是情绪（不可积累，当场消费），局层的奖励是资产（皮肤货币，跨局积累）。夺冠率被人数机制压到 1/60，多数玩家多数局都拿不到大奖——所以设计者必须保证「没夺冠的一局」也有东西可拿（观赏他人翻车的乐子 + 保底货币），否则 59/60 的玩家会在两三局后流失。为失败者设计奖励，是多人游戏循环的必修课。

✏️ 习题 3.3 基础

把下列设计连到对应的时间尺度（秒级 / 分钟级 / 小时级·跨局）：格斗游戏的连招、一局 MOBA 对战、每日委托任务、赛季通行证。

查看答案与解析

答案：连招——秒级；一局 MOBA——分钟级（20–40 分钟为一个完整环）；每日委托——小时级（以「天」为周期的习惯环）；赛季通行证——跨局长线（以「月」为周期的成长环）。

解析：每日委托与赛季通行证这类设计有个共同点：它们不改变游戏本体，只是给已有的环外面再套一个环——你本来就要玩几局（分钟环），委托说「玩三局有额外奖励」（日环），通行证说「攒够日环积分升一级」（季环）。层层套环的本质是把「今天玩不玩」的决策，从零开始的选择变成「断掉可惜」的惯性。它有效，也有味道不对的时候——当你发现自己是为清日常而上线时，重复断裂已经开始了。

✏️ 习题 3.4 基础

一位新手设计师画了这样的循环图：「打怪 → 掉落装备 → 装备卖钱」。这个环有个致命问题，指出来并补上缺的箭头。

查看答案与解析

答案：环没有闭合——钱挣了没处花，是一条死路而不是环。补法：给钱一个能回头放大行动的出口，例如「钱 → 买更好的武器 → 打更强的怪（掉更好的装备）」。

解析：检查循环图的第一件事永远是找不闭合的框：只进不出的资源（囤到天上去的金币）和只出不进的行动（纯付出无回报）。「金币没处花」是真实游戏里极常见的病——玩到后期钱多到花不完，等于毕业断裂提前到来。成熟的经济设计会不断给钱开新出口（修装备、洗练、税、时装……），这正是第 10 章「水龙头与下水道」的主题。

✏️ 习题 3.5 进阶

体力系统故意打断玩家的循环。分别站在玩家立场和厂商立场各写两条理由（玩家为什么讨厌它 / 厂商为什么坚持它），再回答：为什么买断制单机游戏几乎没有体力系统？

查看答案与解析

玩家立场：① 兴致正高时被强制中断，违背自愿参与的精神——「我想玩，游戏不让」；② 它把游戏时间变成配给制，玩家从「主人」变成「领口粮的人」。厂商立场：① 拉长内容消耗周期——内容生产速度追不上无限制的肝，闸门是唯一挡板；② 制造每日回归习惯并创造付费点（买体力）。

单机为什么没有：商业模式不同。买断制在你付款那一刻已完成全部收入，此后你玩得越爽、口碑越好，它不需要你「明天再来」；免费制的收入分布在未来几百天里，必须先把你留到未来。解析：这道题的要义是——循环结构深受商业模式塑造。看到一个「反玩家」的设计，先别急着骂设计师蠢，先查它在哪条收入曲线上工作；多数时候它蠢得很精明。当然，精明不等于无代价——例 2 树脂的口碑账单就是代价。

✏️ 习题 3.6 进阶

「装备毕业后突然不想上线」是毕业断裂的标准症状。给厂商开两个「续命药方」，并各指出它的副作用。

查看答案与解析

药方一：注入新目标——新版本、新装备档次、新玩法（把毕业线往后挪）。副作用：老装备一夜贬值，玩家攒了半年的东西变成废铁，「数值通胀」几个版本后会反噬信任——「反正下版本又白攒，不如现在就退」。

药方二：环外织网——公会、社交绑定、师徒与交易（游戏内目标断了，人际关系还拴着）。副作用：社交绑定挽留的是「不好意思走的人」而非「还想玩的人」，体验债越欠越多，一旦核心几人退坑会引发连锁雪崩。

解析：两个药方分别作用于循环的不同部件——药方一修「奖励」，药方二干脆在循环外面加保险绳。都治标：毕业断裂的根因是成长型循环天然有终点。根治方向是往执行乐趣型挪重心（让玩的过程本身有味道，如竞技玩法赛季重置）——这也是为什么长寿游戏几乎都有一个不依赖数值成长的玩法内核。

✏️ 习题 3.7 挑战

为一个背单词 App 设计秒、日、月三层循环：写出每层的行动、奖励与闸门，并画出循环图。（这是习题 1.5 的升级版——上次你加规则，这次你造系统。）

查看答案与解析

参考设计：秒级环——看词回忆释义（行动）→ 翻面判对错（即时反馈）→ 对了的词进入更长的复习间隔（新局面）。奖励：连对的连击音效。日级环——完成今日 20 词（行动）→ 打卡天数 +1、连击天数保持（奖励）→ 明日词表按今日表现生成（新局面）。闸门：每日新词上限 20 个（防止第一天肝三百个然后再也不来——用限流推迟重复断裂）。月级环——连续打卡与累计词量（行动积累）→ 词库等级徽章、月度报告（奖励）→ 解锁更高阶词库（新局面）。

解析：对照检查三件事：① 每层的奖励是否喂给上一层的动力（月徽章依赖日打卡，日打卡依赖秒级练习）；② 闸门装在哪——注意这里的闸门反而是为玩家好的（记忆科学上分散学习优于集中轰炸），说明闸门本身中性，善恶看用途；③ 最脆弱的环是哪个——是秒级：看词翻面这个动作本身枯燥，正是背单词 App 拼命加连击、音效、进度动画的原因（给最弱的环补即时快感）。工具产品的循环设计和游戏完全同构——这门手艺出了游戏也有用。

选一个你真实弃坑的游戏，写一份「弃坑事故报告」：它断在哪种模式（毕业/卡关/重复）？回头看，断裂前有什么预兆？如果你是设计师，本可以在哪里补救？

查看答案与解析

参考答案（示例：某放置手游）：断裂模式——重复为主、卡关为辅：每天上线清一样的日常，第 40 天左右数值增速骤降，「上线十分钟没有任何变化」。预兆——弃坑前两周已经从「想玩」变成「怕断签到」，上线时长从 40 分钟缩到 5 分钟（只清日常不碰玩法）。补救——在数值放缓的节点本应有新玩法接棒（而不是新数值），例如引入不吃练度的竞技或合作玩法，把重心从成长环挪回执行环。

解析：这份报告最有价值的部分是「预兆」——「只清日常不碰玩法」「怕断签而非想玩」是循环将断的通用前兆，厂商的数据后台看的正是这类指标（在线时长结构、玩法参与率）。养成对自己玩家行为的觉察，是设计师最便宜的用户研究：你自己，就是第一个可以全天候观测的玩家。

✅ 本章要点

① 核心循环 = 行动 → 结果 → 新局面，首尾相接无出口；核心动词被重复上万遍，环本身的手感决定生死；② 奖励分即时快感与积累成长两型，成长型回头放大行动，把环滚成飞轮，飞轮节奏由数值控制；③ 成熟游戏是秒 / 分钟 / 小时三层环的咬合，诊断先分层；④ 断裂三模式对应三个部件——毕业断于奖励、卡关断于成长、重复断于行动；所有环终会断，设计师求的是晚断与体面；⑤ 循环图三约定：圆角框、实线转化、虚线闸门——先找不闭合的框。
