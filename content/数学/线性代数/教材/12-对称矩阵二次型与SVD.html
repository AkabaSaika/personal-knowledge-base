第 12 章 · 对称矩阵、二次型与 SVD

大结局。一路上对称矩阵反复现身，而且每次的特征方向都互相垂直——这一章宣布这是定理（谱定理），再用它看透椭圆的主轴（二次型），最后抵达线性代数的巅峰景观：任何矩阵都能分解成“旋转 · 伸缩 · 旋转”（SVD）。作为告别礼物，我们用它压缩一张图片。

🎯 学习目标

学完本章你能：① 陈述谱定理并对 2×2 对称矩阵做正交对角化 A = QDQᵀ；② 把二次型写成矩阵形式、用特征值判别曲线类型并找出主轴；③ 说出 SVD 的几何意义与 AᵀA 的桥梁作用；④ 解释 PCA 与图像压缩为何是同一个数学动作。

谱定理：对称矩阵的完美骨架

第 9 章习题 9.6、第 10 章例 1、习题 10.3——三个对称矩阵，三对互相垂直的特征方向。这不是巧合：

📐 谱定理（实对称矩阵）

若 Aᵀ = A，则：① 特征值全为实数；② 不同特征值的特征方向互相垂直；③ 总能选出一组由特征向量组成的标准正交基。于是 A = QDQᵀ，其中 Q 是正交矩阵（Q⁻¹ = Qᵀ，第 11 章），D 是特征值对角阵。

几何读法令人愉悦：对称变换 = 转到某组互相垂直的“主轴” → 沿各轴纯拉伸 → 转回来。像拉一块方形橡皮：无论怎么拉，总存在一组互相垂直的方向只被拉长压短、不被扭斜。垂直性的证明只需一行点积（习题 12.5）；“特征值全实”则保证这套骨架总是存在——旋转矩阵那种“无实特征方向”的尴尬，在对称世界里绝不发生。

二次型：藏着矩阵的曲线

形如 f(x, y) = ax² + 2bxy + cy² 的式子叫二次型，它天生是个对称矩阵的“外衣”：

f(v) = vᵀ A v ，   A = ⎡a  b⎤   （对称！交叉项 2bxy 由两个 b 平分）
                       ⎣b  c⎦

麻烦全在交叉项 xy——它让曲线 f = 1 歪着长。谱定理的用法（主轴定理）：换到 A 的特征基（转正主轴），交叉项消失，f = λ₁u² + λ₂w²，曲线类型被特征值符号一锤定音：

特征值符号f = 1 的曲线术语
λ₁, λ₂ 全正椭圆（半轴 1/√λ₁、1/√λ₂，方向 = 特征方向）正定
一正一负双曲线不定
有 0退化（平行直线等）半定
全负空集（f 恒 ≤ 0）负定
🧪 调一调：二次型曲线与它的主轴

💡 三个实验

① 默认 (2, 1, 2)：歪椭圆，金色/青色主轴正是特征方向 (1, 1)、(1, −1)；② 把 b 滑到 0：交叉项消失，椭圆立刻“坐正”，主轴对齐坐标轴；③ 增大 b 越过 √(ac)（如 a = c = 1, b = 2）：det(A) 变负，一正一负，椭圆撕裂成双曲线。

二次型远不止解析几何：多元函数的极值判定（Hessian 正定 ⇒ 极小）、物理的能量函数（动能 ½mv² 的多维版）、统计的协方差结构，全是二次型的舞台。

SVD：所有矩阵的终极分解

谱定理只服务对称矩阵。一般矩阵（甚至非方阵）呢？答案是奇异值分解（SVD）——线性代数的“大一统定理”：

A = U Σ Vᵀ      U、V 正交（旋转/反射），Σ 对角（非负奇异值 σ₁ ≥ σ₂ ≥ …）

几何宣言：任何线性变换都 = 旋转 → 沿垂直轴伸缩 → 再旋转。哪怕是歪七扭八的剪切，也能这样体面地拆开。直观标志：任何矩阵都把单位圆变成一个椭圆（可能退化），椭圆的半轴长就是奇异值：

SVD 与谱定理的桥梁：AᵀA 永远是对称矩阵（(AᵀA)ᵀ = AᵀA），对它用谱定理——AᵀA 的特征值恰是奇异值的平方 σ²，特征向量恰是 V 的列（习题 12.7）。所以求 SVD 的常规路线就是“对 AᵀA 做正交对角化”。

压缩一张图片：SVD 的告别演出

灰度图片就是一个大矩阵（每个元素 = 一个像素亮度）。SVD 把它写成 σ₁u₁v₁ᵀ + σ₂u₂v₂ᵀ + ⋯ 的“分层叠加”，奇异值从大到小排——前几层携带了图像的绝大部分结构，后面的层多是细节与噪声。压缩 = 只保留前 k 层：

  • 存储账本：1000×800 的图片原本要存 80 万个数；保留 50 层只需 50×(1000 + 800 + 1) ≈ 9 万个数，约 11%（习题 12.6）。
  • PCA（主成分分析）：把每条数据记录看成一行，数据云的“主轴”= 协方差矩阵（对称！）的特征方向 = 数据矩阵的右奇异方向。降维 = 只保留方差最大的前几个主轴——与图像压缩是同一个数学动作：抓大放小。
  • 更多舞台：推荐系统的隐语义分解、搜索引擎的潜在语义索引、噪声过滤……凡是“在数据里找最重要的几个方向”，背后都是 SVD。

例题

📘 例 1 · 正交对角化

对 A = ⎡2 1; 1 2⎤ 写出 A = QDQᵀ。

解：第 10 章已求出 λ = 3, 1，方向 (1, 1)、(1, −1)——互相垂直 ✓（谱定理兑现）。归一化排入 Q：Q = (1/√2)⎡1 1; 1 −1⎤，D = diag(3, 1)。由 Q 正交，Q⁻¹ = Qᵀ，故 A = QDQᵀ（可展开验证）。对比第 10 章的一般对角化 PDP⁻¹：这里连逆都不用算——对称矩阵的特权。

📘 例 2 · 二次型判型

判别曲线 2x² + 2xy + 2y² = 1 的类型并给出主轴与半轴长。

解：矩阵 A = ⎡2 1; 1 2⎤（交叉项 2xy ⇒ b = 1），λ = 3, 1 全正 ⇒ 椭圆（正定）。主轴方向 (1, 1) 与 (1, −1)；半轴长 1/√3 ≈ 0.58（短轴，沿 (1, 1)）与 1（长轴，沿 (1, −1)）。注意大特征值对应短半轴——λ 越大该方向“惩罚”越重，等高线被压得越扁。

📘 例 3 · 剪切的奇异值（一个漂亮的彩蛋）

求剪切 A = ⎡1 1; 0 1⎤ 的奇异值。

解：AᵀA = ⎡1 1; 1 2⎤，特征方程 λ² − 3λ + 1 = 0，λ = (3 ± √5)/2。奇异值 σ = √λ：注意 (3+√5)/2 = φ²（φ 为黄金比例），故 σ₁ = φ ≈ 1.618，σ₂ = 1/φ ≈ 0.618。检验：σ₁σ₂ = 1 = |det A| ✓（面积不变的剪切，拉长与压扁恰好互补）。剪切明明“没有对角化的资格”（第 10 章），SVD 照样把它拆成旋转·伸缩·旋转——而且伸缩倍数是黄金比例。

习题

✏️ 习题 12.1 基础

对 A = ⎡1 2; 2 1⎤ 做正交对角化（写出 Q 与 D）。

查看答案与解析

λ = 3, −1，方向 (1, 1)、(1, −1)（习题 10.3）。Q = (1/√2)⎡1 1; 1 −1⎤，D = diag(3, −1)，A = QDQᵀ。

解析：负特征值完全不妨碍谱定理——A 沿 (1, 1) 拉伸 3 倍、沿 (1, −1) 翻转。注意 Q 与例 1 相同：两个矩阵共享一副骨架，只是伸缩倍数不同。

✏️ 习题 12.2 基础

写出二次型 f(x, y) = x² + 4xy + y² 的矩阵，并判别曲线 f = 1 的类型。

查看答案与解析

A = ⎡1 2; 2 1⎤（4xy ⇒ b = 2）。λ = 3, −1 一正一负 ⇒ 双曲线（不定型）。

解析：换到主轴语言 f = 3u² − w²：沿 (1, 1) 方向是“山谷”、沿 (1, −1) 方向是“下坡”——鞍面的等高线正是双曲线。在演示里把 (a, b, c) 调到 (1, 2, 1) 可亲眼看到。

✏️ 习题 12.3 基础

判断 f(x, y) = 5x² + 2xy + y² 是否正定（对一切非零 v 有 f(v) > 0）。

查看答案与解析

A = ⎡5 1; 1 1⎤。tr = 6 > 0，det = 4 > 0 ⇒ 两特征值之和为正、之积为正 ⇒ 全正，正定。（精确值 λ = 3 ± √5 ≈ 5.24, 0.76。）

解析：2×2 正定速判：det > 0 且 tr > 0（等价于教科书的顺序主子式判据 a > 0, det > 0）。正定二次型的等高线是一族同心椭圆，函数图像是“碗”——优化算法最爱的地形。

✏️ 习题 12.4 基础

求下列矩阵的奇异值：(a) diag(3, −2)；(b) ⎡0 2; 0 0⎤。

查看答案与解析

(a) AᵀA = diag(9, 4) ⇒ σ = 3, 2（注意取的是绝对值——奇异值永远非负）。(b) AᵀA = ⎡0 0; 0 4⎤ ⇒ σ = 2, 0。

解析：(b) 的 σ₂ = 0 泄露了秩亏：非零奇异值的个数 = 秩。单位圆的像退化成一条线段——第 8 章“压扁”的 SVD 版本。σ 与特征值别混淆：(a) 的特征值是 3, −2，奇异值是 3, 2；对一般矩阵二者更是两码事（例 3 的剪切：特征值 1, 1，奇异值 φ, 1/φ）。

✏️ 习题 12.5 进阶

证明谱定理的“垂直”部分：若 Aᵀ = A，Au = λ₁u，Av = λ₂v，且 λ₁ ≠ λ₂，则 u ⊥ v。（提示：对称矩阵满足 (Au)·v = u·(Av)。）

查看答案与解析

提示中的恒等式先证一行：(Au)·v = (Au)ᵀv = uᵀAᵀv = uᵀAv = u·(Av)（用了 Aᵀ = A）。于是：λ₁(u·v) = (Au)·v = u·(Av) = λ₂(u·v)，即 (λ₁ − λ₂)(u·v) = 0。由 λ₁ ≠ λ₂ 得 u·v = 0。∎

解析：三行搞定教科书级定理，核心武器全部来自前面章节：转置的乘法规则（第 5 章）+ 点积的矩阵写法（第 3、5 章）。“对称”之所以强大，就在于它允许 A 在点积中自由左右横跳。

✏️ 习题 12.6 进阶

一张 1000×800 的灰度图，用 SVD 保留前 50 个奇异值来压缩。存储量是原图的百分之几？（保留 k 层需存 k 个 σ、k 条 1000 维的 u、k 条 800 维的 v。）

查看答案与解析

压缩后 = 50×(1000 + 800 + 1) = 90 050 个数；原图 = 800 000 个数。比例 ≈ 11.3%。

解析：通用公式 k(m + n + 1)/(mn)——k 远小于 min(m, n) 时收益巨大。真实图片的奇异值衰减极快（往往前 5% 的层就占了 95% 的“能量”），这是该方法有效的经验基础；JPEG 用的变换基不同，但“换基后抓大放小”的哲学一模一样。

✏️ 习题 12.7 挑战

设 A = UΣVᵀ 是 SVD。证明 AᵀA = VΣ²Vᵀ，并由此说明：AᵀA 的特征值 = 奇异值的平方，特征向量 = V 的列。

查看答案与解析

AᵀA = (UΣVᵀ)ᵀ(UΣVᵀ) = VΣᵀUᵀUΣVᵀ = VΣᵀΣVᵀ = VΣ²Vᵀ（U 正交故 UᵀU = I；Σ 对角故 ΣᵀΣ = Σ²）。这恰是 AᵀA 的正交对角化：对角元 σᵢ² 是特征值，V 的列是标准正交特征向量。∎

解析：这条桥梁把“任意矩阵的 SVD”化归为“对称矩阵的谱定理”——理论上闭环，计算上给出求 SVD 的路线（例 3 正是这么算的）。同理 AAᵀ = UΣ²Uᵀ 给出 U。全书的转置规则、正交矩阵、谱定理在最后一题里同台谢幕。

✅ 本章要点

① 谱定理：对称矩阵 = QDQᵀ，特征方向互相垂直、特征值全实；② 二次型 vᵀAv 的曲线类型由特征值符号决定，主轴 = 特征方向；③ SVD：任何矩阵 = UΣVᵀ = 旋转·伸缩·旋转，σ² = AᵀA 的特征值，非零 σ 的个数 = 秩；④ 压缩与 PCA = 保留大奇异值方向、抓大放小。
