第 7 章 · 线性方程组与高斯消元

“鸡兔同笼”是你解过的第一个线性方程组。这一章把中学的消元法升级成一条对任何规模都不出错的流水线——高斯消元，并回答一个更深的问题：方程组什么时候恰有一个解、什么时候无解、什么时候有无穷多个解？两幅几何图景会让答案一目了然。

🎯 学习目标

学完本章你能：① 用“行图景”（直线相交）和“列图景”（配线性组合）双重解读 Ax = b；② 写增广矩阵并熟练执行三种行变换；③ 按流水线完成高斯消元 + 回代；④ 从行阶梯形一眼判断解的三种情况，并写出含自由变量的通解。

同一个方程组，两幅图景

以最简单的二元方程组为例：

x + y = 3
x − y = 1        （解：x = 2, y = 1）

行图景（一行一条线）：每个方程是平面上一条直线，解 = 所有直线的公共交点。三元方程组则是三张平面找公共点。

列图景（一列一根向量）：把方程组竖着读，它问的是——“系数矩阵的列如何组合出右端向量？”

x·⎡1⎤ + y·⎡ 1⎤ = ⎡3⎤
  ⎣1⎦     ⎣−1⎦   ⎣1⎦

这正是第 2 章例 1 做过的“配出目标向量”！Ax = b 的三种身份从此打通：解方程组 = 求线性组合系数 = 反求变换的输入。行图景直观、列图景深刻，判断“有没有解”时列图景尤其有力（见习题 7.7）。

🧪 两条直线的三种命运：唯一解 / 无解 / 无穷多解
固定：x + y = 3
可调：x + b·y = c

💡 亲手制造三种命运

① 默认 b = −1, c = 1：两线相交于 (2, 1)，唯一解；② 把 b 滑到 1、c ≠ 3（比如 5）：两线平行——方程“x + y = 3 且 x + y = 5”自相矛盾，无解；③ b = 1 且 c = 3：两线重合，整条线上的点都是解，无穷多。三种情况之间只隔一次滑动。

增广矩阵与行变换

消元时真正参与运算的只有系数和右端数，把它们抄进一张表——增广矩阵 [A | b]，解方程就变成对行的操作。合法操作只有三种（都不改变解集，因为每步可逆）：

  1. 交换两行（方程排列顺序无关紧要）；
  2. 某行乘非零常数（方程两边同乘）；
  3. 某行加上另一行的倍数（消元的主力）。

消元流水线：一个 3×3 全过程

目标形态是行阶梯形：像下楼梯一样，每行第一个非零数（主元）都比上一行更靠右，主元下方全是 0。到位后从最后一行往回代入。完整走一遍：

  x +  y +  z = 6            ⎡ 1  1  1 | 6 ⎤
 2x −  y +  z = 3     增广 → ⎢ 2 −1  1 | 3 ⎥
  x + 2y −  z = 2            ⎣ 1  2 −1 | 2 ⎦

① R2 ← R2 − 2·R1（消掉第 2 行的 x）
   R3 ← R3 − 1·R1（消掉第 3 行的 x）
                             ⎡ 1  1  1 |  6 ⎤
                             ⎢ 0 −3 −1 | −9 ⎥
                             ⎣ 0  1 −2 | −4 ⎦

② R2 ↔ R3（把系数简单的行换上来当主元行）
                             ⎡ 1  1  1 |  6 ⎤
                             ⎢ 0  1 −2 | −4 ⎥
                             ⎣ 0 −3 −1 | −9 ⎦

③ R3 ← R3 + 3·R2（消掉第 3 行的 y）
                             ⎡ 1  1  1 |  6 ⎤      ← 行阶梯形，
                             ⎢ 0  1 −2 | −4 ⎥        主元 1, 1, −7
                             ⎣ 0  0 −7 | −21⎦

④ 回代：−7z = −21 ⇒ z = 3
        y − 2z = −4 ⇒ y = −4 + 6 = 2
        x + y + z = 6 ⇒ x = 6 − 2 − 3 = 1

解为 (x, y, z) = (1, 2, 3)。代回原方程组逐条验证 ✓。流水线要诀：自上而下逐列清零，自下而上逐个回代；遇到主元位置是 0 就先换行。

解的三种情况：看阶梯形一眼定案

消元结束后，答案写在阶梯形的脸上：

阶梯形特征结论几何图景（二元情形）
出现 [0 0 … 0 | 非零] 行无解（0 = 非零，矛盾）直线平行不相交
无矛盾行，主元数 = 未知数个数唯一解直线交于一点
无矛盾行，主元数 < 未知数个数无穷多解（有自由变量）直线重合

无穷多解时，没分到主元的未知数称自由变量：给它随便赋一个值，其余未知数就被唯一确定。把自由变量记作参数 t，就得到通解——一条“解的直线”（见习题 7.6）。

例题

📘 例 1 · 二元小试

解方程组：2x + y = 7；x − y = 2。

解：增广矩阵 ⎡2 1 | 7; 1 −1 | 2⎤。R1 ↔ R2（让主元为 1 更省心）→ ⎡1 −1 | 2; 2 1 | 7⎤；R2 ← R2 − 2R1 → ⎡1 −1 | 2; 0 3 | 3⎤。回代：3y = 3 ⇒ y = 1；x = 2 + y = 3。解 (3, 1)。行图景：两直线交于 (3, 1)；列图景：3·(2, 1) + 1·(1, −1) = (7, 2) ✓。

📘 例 2 · 一眼判型

下面两个增广矩阵已是阶梯形，各判断解的情况：(a) ⎡1 2 | 4; 0 0 | 5⎤；(b) ⎡1 2 −1 | 3; 0 1 4 | 1; 0 0 0 | 0⎤。

解：(a) 第二行读作 0 = 5，无解。(b) 无矛盾行；3 个未知数只有 2 个主元（x、y 列），z 是自由变量，无穷多解。全零行 [0 0 0 | 0] 只是“废话方程 0 = 0”，不添乱也不帮忙。

习题

✏️ 习题 7.1 基础

用增广矩阵和行变换解：x + 2y = 5；3x − y = 1。

查看答案与解析

⎡1 2 | 5; 3 −1 | 1⎤，R2 ← R2 − 3R1 → ⎡1 2 | 5; 0 −7 | −14⎤。y = 2，x = 5 − 4 = 1。解 (1, 2)。

解析：养成“先写增广矩阵、每步标注行变换”的习惯——三元以上时这份纪律就是你不出错的保险。

✏️ 习题 7.2 基础

解三元方程组：x + y + z = 2；2x + 3y + z = 5；x − y + 2z = −1。

查看答案与解析

消元：R2 ← R2 − 2R1 → (0, 1, −1 | 1)；R3 ← R3 − R1 → (0, −2, 1 | −3)；R3 ← R3 + 2R2 → (0, 0, −1 | −1)。回代：z = 1，y = 1 + z = 2，x = 2 − y − z = −1。解 (−1, 2, 1)。

解析：与正文例子完全同一套流水线。做完务必代回第 3 个原方程验证（−1 − 2 + 2 = −1 ✓）——回代验证的成本远低于重算一遍。

✏️ 习题 7.3 基础

判断下列阶梯形增广矩阵对应方程组的解情况（不必求解）：(a) ⎡1 0 2 | 1; 0 1 3 | 2; 0 0 1 | 4⎤；(b) ⎡1 5 | 2; 0 0 | 0⎤；(c) ⎡1 1 1 | 1; 0 1 2 | 3; 0 0 0 | 7⎤。

查看答案与解析

(a) 3 主元 = 3 未知数，无矛盾行：唯一解。(b) 1 主元 < 2 未知数，无矛盾行：无穷多解（y 自由）。(c) 末行 0 = 7：无解。

解析：判型三步：①找矛盾行；②数主元；③与未知数个数比较。顺序固定，永不失手。

✏️ 习题 7.4 基础

把方程组 x + 2y − z = 3；2x + 4y − 2z = 6 化成阶梯形，说明几何图景（提示：这是三维空间中的两张平面）。

查看答案与解析

R2 ← R2 − 2R1 → ⎡1 2 −1 | 3; 0 0 0 | 0⎤。第二个方程是第一个的 2 倍——两张重合的平面。1 个主元、3 个未知数：无穷多解，y、z 都是自由变量，解集就是这张平面本身（二维的解集）。

解析：自由变量的个数 = 解集的“维数”：0 个 → 一个点，1 个 → 一条线，2 个 → 一张面。这个计数在第 8 章将正名为“零空间的维数”。

✏️ 习题 7.5 进阶

讨论参数 k：方程组 kx + y = 1；x + ky = 1 何时唯一解、无穷多解、无解？

查看答案与解析

系数行列式 det = k² − 1。k ≠ ±1：det ≠ 0，唯一解（可解出 x = y = 1/(k+1)）。k = 1：两方程都是 x + y = 1，无穷多解。k = −1：−x + y = 1 与 x − y = 1 相加得 0 = 2，无解。

解析：参数题的高效路径——先算 det 锁定“唯一解”的范围，再把临界值逐个代入细判。det 在这里扮演“预警器”：det = 0 处正是几何上两直线变平行/重合的时刻，也呼应第 6 章“det = 0 ⇔ 降维”。

✏️ 习题 7.6 进阶

求方程组 x + y + z = 3；x − y + z = 1 的通解，并把它写成“特解 + 参数×方向”的形式。

查看答案与解析

两式相减：2y = 2 ⇒ y = 1；于是 x + z = 2，z 自由。令 z = t：(x, y, z) = (2 − t, 1, t) = (2, 1, 0) + t·(−1, 0, 1)。

解析：解集是三维空间中一条直线：过“特解” (2, 1, 0)，沿方向 (−1, 0, 1) 无限延伸。这个方向向量恰满足“代入方程组右端得 0”（齐次解）——通解 = 特解 + 齐次解 的结构下一章将升级为“特解 + 零空间”。

✏️ 习题 7.7 挑战

构造一个 2×2 方程组使其无解，并分别用行图景与列图景解释“为什么无解”。

查看答案与解析

例如：x + y = 1；2x + 2y = 5。消元得 0 = 3，无解。

行图景：两条直线斜率相同（都是 −1）而截距不同——平行线永不相交，不存在公共点。

列图景：问 x·(1, 2) + y·(1, 2) 能否等于 (1, 5)。两列共线，一切组合都被困在直线 span((1, 2)) 上，而 (1, 5) 不在这条直线上（5 ≠ 2×1）——右端向量落在列张成之外，故无解。∎

解析：列图景把“无解”翻译成一句话：b 不在 A 的列所张成的空间里。这句话在第 8 章有专名——b ∉ 列空间 C(A)；第 11 章的最小二乘法则回答“无解时怎么办”：在列空间里找离 b 最近的点。一条线索贯穿三章。

✅ 本章要点

① Ax = b 三重身份：直线找交点（行）、列配组合（列）、变换反求输入；② 三种行变换不改变解集，流水线 = 消成阶梯形 + 回代；③ 判型三步：矛盾行 → 数主元 → 比未知数；④ 无穷多解时通解 = 特解 + 自由参数×方向。
下一章预告：什么时候 Ax = b 对任何 b 都恰有一解？答案牵出四个互相咬合的概念：逆矩阵、列空间、零空间与秩——矩阵篇的收官之战。
