第 3 章 · 点积：长度、夹角与投影

前两章的加法和数乘能让我们“到达”任何位置，却回答不了两个最基本的几何问题：这个向量有多长？两个向量夹角多大？点积一次补齐这两块拼图——它把两个向量变成一个数，而这个数里同时编码着长度与角度的信息。

🎯 学习目标

学完本章你能：① 熟练计算点积、模长和单位向量；② 只看点积符号就说出夹角是锐角、直角还是钝角；③ 计算一个向量在另一个向量上的投影，并把向量分解成平行 + 垂直两部分；④ 用余弦相似度比较两组数据的“方向”。

从影子说起

傍晚的阳光斜照，你手中的杆子在地面投下影子：杆子越贴近地面，影子越长；杆子竖直时，影子缩成一点。“一个向量在另一个方向上占了多少分量”——这个日常直觉，正是点积要度量的东西。物理里它早有名字：力沿位移方向做的功 W = F·d·cosθ，只有“顺着走的那部分力”才算数。

点积的代数定义

两个同维向量的点积（又称内积）：对应分量相乘再求和，结果是一个数（标量），不再是向量：

u · v = u₁v₁ + u₂v₂ + ⋯ + uₙvₙ
例：(2, 3) · (4, 1) = 2×4 + 3×1 = 11

点积满足交换律 u·v = v·u、分配律 u·(v + w) = u·v + u·w，数乘可自由进出：(ku)·v = k(u·v)。这让点积式子可以像多项式一样展开——本章两道挑战题全靠它。

模长与单位向量

向量与自己做点积，得到的是各分量平方和——由勾股定理，这正是长度的平方。于是模长（长度）：

|v| = √(v · v) = √(v₁² + v₂² + ⋯ + vₙ²)      例：|(3, 4)| = √25 = 5

长度为 1 的向量称单位向量，只表示“方向”。把任何非零向量除以自己的模长（数乘 1/|v|），就得到同方向的单位向量，这一步叫归一化：(3, 4) 归一化为 (3/5, 4/5)。

几何式：点积藏着夹角

点积还有第二张面孔。设 θ 为 u、v 的夹角（0° ≤ θ ≤ 180°），则：

u · v = |u| |v| cosθ

两个式子算的是同一个数：代数式负责快速计算，几何式负责解读含义。由于 |u|、|v| 恒正，点积的符号完全由 cosθ 决定：

点积符号夹角直觉
u·v > 0锐角（< 90°）两向量“大体同向”
u·v = 0直角（= 90°）垂直（正交），互不沾边
u·v < 0钝角（> 90°）两向量“大体反向”

把几何式变形，就得到求夹角的万能公式：cosθ = u·v / (|u||v|)。

🧪 拖一拖：点积、夹角与影子
拖动 u、v 端点。橙色线段是 u 在 v 上的投影

💡 试试这三个位置

① 把 u 转到与 v 垂直——点积读数会掠过 0，影子缩成一点；② 转到钝角侧——点积变负，影子跑到 v 的反方向；③ 与 v 完全同向——点积达到最大值 |u||v|。

投影：把“影子”算出来

u 在 v 方向上的“影子”有两种表述：

  • 标量投影（影子的带符号长度）：compv u = u·v / |v|，负号表示影子落在 v 的反方向；
  • 向量投影（影子本身，作为向量）：projv u = (u·v / |v|²) v，即“影子长度 × v 方向的单位向量”。

投影立刻带来一个常用操作——正交分解：u = projv u + (u − projv u)，前者平行于 v，后者垂直于 v（可用点积验证）。斜面上的重力分解、把数据拆成“趋势 + 噪声”，用的都是它。第 11 章的最小二乘法，本质就是一次大型投影。

应用一瞥

  • 余弦相似度：把两篇文章、两个用户的行为各编码成向量，cosθ = u·v/(|u||v|) 越接近 1 方向越一致——推荐系统“猜你喜欢”的入门原理。它只比方向、不比长短：评分习惯偏严的用户照样能匹配到同好。
  • 物理做功：W = F·s。力垂直于位移时不做功（点积为零），逆着位移时做负功。
  • 游戏 AI 的方向感：设角色朝向 f，指向敌人的向量 e，则 f·e > 0 说明敌人在前方，< 0 在背后——一次乘加就完成“视野判断”。

例题

📘 例 1 · 求夹角

求 u = (1, 2) 与 v = (3, 1) 的夹角。

解：u·v = 3 + 2 = 5；|u| = √5，|v| = √10。cosθ = 5/(√5·√10) = 5/√50 = 1/√2，故 θ = 45°。
流程固定：先代数式算点积，再套 cosθ 公式。

📘 例 2 · 求投影并分解

求 u = (3, 4) 在 v = (2, 1) 上的向量投影，并把 u 分解为平行与垂直于 v 的两部分。

解：u·v = 10，|v|² = 5，故 projv u = (10/5)v = (4, 2)。垂直部分 = u − (4, 2) = (−1, 2)。验证：(−1, 2)·(2, 1) = −2 + 2 = 0 ✓。于是 (3, 4) = (4, 2) + (−1, 2)，前者沿 v，后者垂直于 v。

📘 例 3 · 构造垂直向量

求与 a = (3, 4) 垂直的所有单位向量。

解：平面上把 (x, y) 换成 (−y, x)（逆时针转 90°）必与原向量垂直：得 (−4, 3)，检验 3×(−4) + 4×3 = 0 ✓。归一化：|(−4, 3)| = 5，故答案为 (−4/5, 3/5) 与 (4/5, −3/5) 两个（顺、逆时针各一）。“交换分量、给一个添负号”是平面内造垂直向量的速记法。

习题

✏️ 习题 3.1 基础

设 u = (2, −3)，v = (4, 1)，w = (1, 2, 2)。计算：(a) u·v；(b) |u|；(c) |w|。

查看答案与解析

(a) 8 − 3 = 5；(b) √(4+9) = √13；(c) √(1+4+4) = 3。

解析：点积=对应相乘再相加；模长=自点积开根号，维数多少都一样。(1, 2, 2) 这类“勾股整数组”在习题里很常见，见到分量 1,2,2 或 3,4 可直接反应出模长。

✏️ 习题 3.2 基础

只用点积符号，判断下列各对向量的夹角是锐角、直角还是钝角：(a) (1, 3) 与 (2, 1)；(b) (2, −1) 与 (1, 2)；(c) (1, 1) 与 (−3, 1)。

查看答案与解析

(a) 点积 = 5 > 0，锐角；(b) 点积 = 0，直角；(c) 点积 = −2 < 0，钝角。

解析：判断角的类型不需要算出角度本身——符号就够了。这也是工程代码里最高频的点积用法（快、且避免反三角函数）。

✏️ 习题 3.3 基础

把 v = (6, 8) 归一化。再求与 v 同方向、长度为 2.5 的向量。

查看答案与解析

|v| = 10，单位向量 = (0.6, 0.8)；长度 2.5 的同向向量 = 2.5 × (0.6, 0.8) = (1.5, 2)。

解析：“先归一化拿到纯方向，再按需伸缩”是图形学与物理引擎的日常操作（如把移动速度限定为常值）。

✏️ 习题 3.4 基础

t 取什么值时，(2, t) 与 (3, 6) 垂直？

查看答案与解析

垂直 ⇔ 点积为零：2×3 + 6t = 0，解得 t = −1。

解析：“垂直”翻译成方程就是一次点积。对比第 2 章习题 2.5 的“共线求参”，你已经能把两种最重要的几何关系（平行、垂直）都转成代数方程了。

✏️ 习题 3.5 进阶

设 u = (4, 2)，v = (3, 0)。(a) 求标量投影与向量投影 projv u；(b) 把 u 分解为平行与垂直于 v 的两部分并验证。

查看答案与解析

(a) u·v = 12，|v| = 3，标量投影 = 12/3 = 4；projv u = (12/9)(3, 0) = (4, 0)。(b) 垂直部分 = (4, 2) − (4, 0) = (0, 2)；验证 (0, 2)·(3, 0) = 0 ✓，且 (4, 0) + (0, 2) = u ✓。

解析：v 沿 x 轴，所以“影子”就是 u 的 x 分量——坐标分量本来就是在标准基方向上的投影！这个观察把“坐标”与“投影”两个概念焊在了一起。

✏️ 习题 3.6 进阶

两位用户对三部电影的评分：甲 = (5, 4, 1)，乙 = (4, 5, 2)，丙 = (1, 2, 5)。用余弦相似度判断：乙的口味更接近甲还是丙？

查看答案与解析

cos(甲, 乙) = (20+20+2)/(√42·√45) ≈ 42/43.5 ≈ 0.966；cos(乙, 丙) = (4+10+10)/(√45·√30) ≈ 24/36.7 ≈ 0.653。乙与甲更相似。

解析：甲乙都“爱前两部、冷落第三部”，方向接近；丙的偏好几乎相反。注意余弦相似度只看比例结构：把甲的评分整体翻倍，相似度不变——这正是我们想要的“口味”而非“打分尺度”。

✏️ 习题 3.7 挑战

用点积证明：|u + v|² = |u|² + |v|² 当且仅当 u ⊥ v（即勾股定理及其逆定理）。

查看答案与解析

展开：|u + v|² = (u + v)·(u + v) = u·u + 2u·v + v·v = |u|² + |v|² + 2u·v。因此等式成立 ⇔ 2u·v = 0 ⇔ u·v = 0 ⇔ 垂直。∎

解析：把模长写成自点积，再用分配律像乘法公式一样展开——(a+b)² 的向量版。两千年前的勾股定理在点积语言里只是两行代数；这套展开技巧在第 11 章（正交性）会反复出现。

✏️ 习题 3.8 挑战

证明柯西–施瓦茨不等式：|u·v| ≤ |u||v|，并说明等号何时成立。提示：可从几何式出发，或考虑函数 f(t) = |u + tv|² ≥ 0。

查看答案与解析

几何式证法：u·v = |u||v|cosθ，而 |cosθ| ≤ 1，两边取绝对值即得。等号 ⇔ cosθ = ±1 ⇔ u、v 共线。

代数证法（不依赖“夹角”概念，任意维都严格）：f(t) = |v|²t² + 2(u·v)t + |u|² 是恒非负的二次函数（v ≠ 0 时），判别式必须 ≤ 0：4(u·v)² − 4|v|²|u|² ≤ 0，整理即得。∎

解析：高维空间里“夹角”本是未定义的——正是这条不等式保证 u·v/(|u||v|) 落在 [−1, 1]，反过来让我们用点积去定义高维夹角。余弦相似度对 500 维的用户向量有意义，靠的就是它。

✅ 本章要点

① 点积两张面孔：分量乘加（算）= |u||v|cosθ（想）；② 模长 = √(自点积)，归一化提取纯方向；③ 符号定角：正锐、零直、负钝；④ 投影 projv u = (u·v/|v|²)v，由此可作正交分解。
