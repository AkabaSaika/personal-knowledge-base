第 2 章 · 线性组合、张成与线性无关

上一章我们学会了向量仅有的两种运算：加法和数乘。这一章问一个自然的问题：把它们反复组合，能到达哪些地方？这个问题的答案（张成），以及“哪些向量是多余的”（线性相关），构成了线性代数最核心的一组概念。

🎯 学习目标

学完本章你能：① 计算并从几何上解读线性组合 au + bv；② 说出一组向量张成的空间是点、直线还是平面；③ 用定义和快捷判据判断向量组线性相关或无关；④ 解释“基”为什么恰好要“无关又张满”。

调色盘：两种原料能配出什么

想象你手里有两管颜料：红和蓝。取“2 份红 + 1 份蓝”“0.5 份红 + 3 份蓝”……不同配比能调出一整族紫色。向量也一样：给定 u 和 v，取遍所有系数 a、b，表达式

a·u + b·v      （a、b 是任意实数）

能“调配”出的所有向量，就是 u、v 的全部线性组合。用第 1 章的走路比喻：沿 u 方向走 a 步、再沿 v 方向走 b 步，所有能走到的位置。

🧪 调一调：线性组合能扫出哪些点

💡 关键实验

先随意滑动 a、b——红点的“脚印”会逐渐铺满整个平面。然后勾选“让 v 与 u 共线”再滑：无论怎么调，红点都被困在一条直线上。整章的核心直觉就在这一勾之间。

张成（span）：所有能到达的地方

一组向量的张成，记作 span(u, v, …)，定义为它们全部线性组合构成的集合——即“反复用加法和数乘能到达的所有位置”。平面上只有三种可能：

向量组张成几何图景
只有零向量一个点 {0}哪儿也去不了
一个非零向量 u（或多个共线向量）过原点的直线只能沿一个方向来回
两个不共线向量 u、v整个平面 ℝ²任何点都可到达，且走法唯一

三维空间中同理多一档：两个不共线向量张成一张过原点的平面（薄薄一片，撑不满空间），三个“不共面”的向量才张成整个 ℝ³。注意：span 永远包含原点（取全部系数为 0），所以张成的直线、平面都过原点。

线性相关：谁是多余的

上面实验里，当 v 与 u 共线时，v 没有贡献任何新方向——它本来就在 span(u) 里，是冗余的。这就是线性相关的直观含义：

📐 定义

一组向量线性相关，如果其中某个向量落在其余向量的张成里（可由其余向量线性组合而出）；否则称线性无关——每个向量都贡献了新方向，谁也替代不了谁。

教材里更常见的是等价的“官方定义”：向量组 v₁, …, vₖ 线性相关，当且仅当存在不全为零的系数使 c₁v₁ + ⋯ + cₖvₖ = 0。两个说法是一回事：若 c₁ ≠ 0，移项即可把 v₁ 用其余向量表示出来。官方定义的好处是检验时只需解一个方程。

几个立刻可用的快捷判据：

  • 两个向量：相关 ⇔ 共线（一个是另一个的数乘）。
  • 含零向量的组：必相关（零向量永远冗余）。
  • 平面上任意三个向量：必相关——平面只有两个独立方向，第三个向量一定能被前两个配出来（只要前两个不共线）。一般地：ℝⁿ 中超过 n 个向量必相关。

基与维数：恰到好处的一组向量

要描述平面上的所有点，向量组需要满足两个条件：张成整个平面（够用）、线性无关（不浪费）。同时满足这两条的向量组称为基。最熟悉的例子是标准基 e₁ = (1, 0)、e₂ = (0, 1)：任何 (x, y) 都能唯一写成 xe₁ + ye₂——坐标本身就是“在标准基下的组合系数”。

但标准基不是唯一选择：任何两个不共线的向量都能当平面的基。不同的基好比不同的坐标语言，同一个点在不同语言里有不同“名字”（坐标）。所有基的向量个数都相同——这个不变的个数就是空间的维数：平面是 2 维，空间是 3 维。（“换语言”的完整故事在第 9 章。）

例题

📘 例 1 · 配出目标向量

把 w = (5, 4) 表示为 u = (1, 2) 与 v = (3, 0) 的线性组合。

解：设 a(1, 2) + b(3, 0) = (5, 4)。按分量列方程：a + 3b = 5，2a = 4。由第二式 a = 2，代入第一式得 b = 1。所以 w = 2u + v。
“能否配出、怎样配出”永远归结为解方程组——第 7 章的高斯消元将把这件事做成流水线。

📘 例 2 · 判定相关性

判断向量组的相关性：(a) (1, 2) 与 (2, 4)；(b) (1, 2) 与 (2, 3)；(c) (1, 2)、(2, 3)、(3, 1)。

解：(a) (2, 4) = 2(1, 2)，共线，相关。(b) 若 (2, 3) = k(1, 2)，则 k = 2 且 k = 1.5，矛盾，无关。(c) 平面上三个向量必相关；具体地，由 (b) 知前两个已张成整个平面，故 (3, 1) 必可被配出：解 a(1, 2) + b(2, 3) = (3, 1) 得 a = −7, b = 5，即 −7(1, 2) + 5(2, 3) − (3, 1) = 0。

习题

✏️ 习题 2.1 基础

设 u = (2, −1)，v = (1, 3)。计算线性组合 3u − 2v，并用“走路”语言描述它。

查看答案与解析

3u − 2v = (6, −3) − (2, 6) = (4, −9)。

解析：沿 u 方向走 3 步，再沿 v 的反方向走 2 步。任何线性组合都可以这样读，系数就是各方向的“步数”（可为负、可为小数）。

✏️ 习题 2.2 基础

判断下列向量组线性相关还是无关：(a) (3, 6) 与 (1, 2)；(b) (1, 0) 与 (1, 1)；(c) (2, 5) 与 (0, 0)。

查看答案与解析

(a) 相关：(3, 6) = 3(1, 2)。(b) 无关：显然不共线（一个水平，一个斜向）。(c) 相关：含零向量的组必相关，例如 0·(2, 5) + 7·(0, 0) = 0 就是不全为零的系数组合。

解析：两个向量看共线，含零向量直接判相关——先用快捷判据，再谈解方程。

✏️ 习题 2.3 基础

w = (1, 7) 能否写成 u = (1, 1) 与 v = (1, −1) 的线性组合？若能，求出系数。

查看答案与解析

能：设 a + b = 1，a − b = 7，两式相加得 a = 4，故 b = −3。即 w = 4u − 3v。

解析：u、v 不共线，张成整个平面，所以任何向量都必然能配出，且配法唯一。系数 (4, −3) 其实就是 w 在基 {u, v} 下的坐标。

✏️ 习题 2.4 基础

span((2, −4)) 是什么图形？再把 (1, −2) 加入向量组，张成变大了吗？

查看答案与解析

span((2, −4)) 是过原点、方向为 (1, −2) 的一条直线。加入 (1, −2) 后张成不变——它与 (2, −4) 共线（(2, −4) = 2(1, −2)），本来就在这条直线上。

解析：加入相关向量不改变 span。想让张成升级成整个平面，必须加入一个不在这条直线上的向量。

✏️ 习题 2.5 进阶

t 取什么值时，(1, 2) 与 (t, 6) 线性相关？此时二者的 span 是什么？

查看答案与解析

相关 ⇔ 共线 ⇔ (t, 6) = k(1, 2)。由第二分量 k = 3，故 t = 3。此时 span 是过原点、方向 (1, 2) 的直线；t ≠ 3 时两向量无关，span 是整个平面。

解析：也可用交叉相乘：共线 ⇔ 1×6 − 2×t = 0。这个“交叉相乘检验式”其实是 2×2 行列式——第 6 章会揭示它的几何身份（平行四边形面积为零）。

✏️ 习题 2.6 进阶

设 u、v 线性无关。证明 u + v 与 u − v 也线性无关。

查看答案与解析

设 a(u + v) + b(u − v) = 0。整理得 (a + b)u + (a − b)v = 0。由 u、v 无关，系数必须全为零：a + b = 0 且 a − b = 0，解得 a = b = 0。只有平凡组合，故无关。∎

解析：标准套路三步走：设组合为零 → 整理成已知无关组的组合 → 用无关性逼出系数全零。几何上看，对角线方向 u+v 与 u−v 显然不共线，代数证明正是这个直觉的严格化。

✏️ 习题 2.7 挑战

三维向量 (1, 1, 0)、(0, 1, 1)、(1, 0, −1) 是否线性相关（即是否共面）？若相关，写出一个不全为零的零组合。

查看答案与解析

相关。观察：(1, 1, 0) − (0, 1, 1) = (1, 0, −1)，即第三个向量 = 第一减第二。移项得零组合：(1, 1, 0) − (0, 1, 1) − (1, 0, −1) = 0，系数 (1, −1, −1) 不全为零。

解析：三个向量相关，几何上意味着它们挤在同一张过原点的平面里，撑不起三维空间。找不到明显关系时，通用做法是解方程组 c₁v₁ + c₂v₂ + c₃v₃ = 0（第 7 章），或算行列式是否为零（第 6 章）。这道题是后面两章工具的“预告片”。

✅ 本章要点

① 线性组合 = 各方向按系数走步；② span = 能到达的全部位置，平面上只有点/直线/全平面三档；③ 相关 = 有向量冗余，官方判据是“存在不全为零的零组合”；④ 基 = 无关 + 张满，基向量个数 = 维数。
下一章预告：加法和数乘让我们“到达”各个位置，但还量不了长度、判不了角度。第 3 章引入第三种运算——点积，几何测量将全面上线。
