第 6 章 · 行列式：变换的缩放因子

上一章遗留了一个问题：变换把平面拉伸、挤压之后，面积变成了原来的多少倍？答案是一个随矩阵而定的数——行列式。它还免费附赠两条信息：符号告诉你空间有没有被“翻面”，取值为零则宣告发生了“压扁降维”事故。

🎯 学习目标

学完本章你能：① 说出行列式的几何定义（带符号的面积缩放因子）；② 熟练计算 2×2 与 3×3 行列式；③ 解释 det < 0 与 det = 0 各自的几何含义；④ 使用 det(AB) = det(A)·det(B) 等性质；⑤ 用行列式判共线、算多边形面积。

盯住一块单位方块

要量“面积放大几倍”，不必检查整个平面：线性变换对所有区域一视同仁（网格均匀变形），所以盯住一块样板就够了——就选 î、ĵ 张成的单位正方形（面积 1）。变换后它成为 A 的两列张成的平行四边形。这个平行四边形的面积，就是所有图形面积的公共缩放倍数，称为行列式 det(A)。

2×2 的计算公式：

det ⎡a  b⎤ = ad − bc
    ⎣c  d⎦

先动手感受，再谈符号与性质：

🧪 拖一拖：平行四边形的面积就是行列式
拖动 î 的落点与 ĵ 的落点，观察面积与符号

💡 三个必做实验

① 把 ĵ 的落点拖过 î 所在直线的另一侧——平行四边形变红，det 变负：空间被“翻面”了（想象把一张纸翻过来）；② 让两个落点共线——面积归零，det = 0，平面被压扁成直线（上一章“压成直线!”按钮的定量版）；③ 把 î 拖到 (2, 0)、ĵ 拖到 (0, 3)——det = 6，正是 2×3 的矩形。

符号：定向的翻转

面积不该是负数，为什么 det 可以为负？因为它是带符号的面积：符号记录“定向”。原本从 î 逆时针转到 ĵ 经过 90°；若变换后“新 î 转到新 ĵ”变成了顺时针方向，说明平面被翻了面（像照镜子），det 记为负。反射矩阵 ⎡1 0; 0 −1⎤ 的 det = −1：面积不变、但翻了面。

det = 0：降维事故的判决书

det(A) = 0 ⇔ 平行四边形面积为零 ⇔ A 的两列共线（线性相关）⇔ 整个平面被压进一条直线（或一个点）。回看第 2 章习题 2.5 的“交叉相乘检验式” 1×6 − 2×t——它其实就是行列式！判共线/判线性相关，算一个 det 就够了。压扁意味着信息丢失、无法逆转，这将在第 8 章成为“矩阵不可逆”的判据。

常用性质

性质几何理由
det(AB) = det(A) · det(B)先缩放 det(B) 倍、再缩放 det(A) 倍，总倍数相乘
det(I) = 1“什么都不做”不改变面积
det(kA) = k²·det(A)（2×2）两列各放大 k 倍，面积放大 k×k 倍
三角矩阵：det = 对角元素之积底×高：另一列的斜移（剪切）不改变面积
交换两列，det 变号î 与 ĵ 互换位置恰是一次“翻面”
det(Aᵀ) = det(A)行与列的地位在行列式里对称（结论不显然，先记住）

旋转矩阵 det = 1（面积、定向都不变），剪切矩阵 det = 1（推歪但不改面积——底不变高不变）。“det = 1 的变换保面积”，这一类变换在物理与图形学里格外重要。

3×3：体积的缩放

三维同理：det 是单位立方体变换后（平行六面体）的带符号体积缩放因子。计算用按行展开（余子式展开）：沿第一行，每个元素乘上“划掉所在行列后剩下的 2×2 行列式”，符号按 +、−、+ 交替：

det ⎡a₁ a₂ a₃⎤
    ⎢b₁ b₂ b₃⎥ = a₁·det⎡b₂ b₃⎤ − a₂·det⎡b₁ b₃⎤ + a₃·det⎡b₁ b₂⎤
    ⎣c₁ c₂ c₃⎦        ⎣c₂ c₃⎦        ⎣c₁ c₃⎦        ⎣c₁ c₂⎦

例题

📘 例 1 · 计算与解读

求 det ⎡3 1; 1 2⎤ 并解读其几何含义。

解：det = 3×2 − 1×1 = 5。含义：该变换把一切图形的面积放大 5 倍，且不翻面（正号）；等价地，列向量 (3, 1) 与 (1, 2) 张成的平行四边形面积为 5。

📘 例 2 · 特殊变换的 det

不用公式硬算，直接说出旋转 R(θ)、剪切 ⎡1 k; 0 1⎤、反射 ⎡0 1; 1 0⎤ 的行列式。

解：旋转不改面积不翻面，det = 1（验证：cos²θ + sin²θ = 1）；剪切“推歪不改面积”，det = 1；反射面积不变但翻面，det = −1。先几何判断、再公式验证，是行列式的正确打开方式。

📘 例 3 · 3×3 展开

求 det A，A = ⎡2 0 1; 1 3 0; 0 1 1⎤。

解：沿第一行展开：2·det⎡3 0; 1 1⎤ − 0·(…) + 1·det⎡1 3; 0 1⎤ = 2×(3−0) − 0 + 1×(1−0) = 7。技巧：优先沿含 0 多的行/列展开，可跳过整项计算。

习题

✏️ 习题 6.1 基础

计算下列行列式，并各用一句话解读：(a) ⎡2 1; 3 4⎤；(b) ⎡1 2; 2 4⎤；(c) ⎡0 1; 1 0⎤。

查看答案与解析

(a) 8 − 3 = 5：面积放大 5 倍，不翻面。(b) 4 − 4 = 0：两列共线，平面被压扁成直线。(c) 0 − 1 = −1：面积不变但定向翻转（这是交换 x、y 的反射）。

解析：算完 det 养成“报三件事”的习惯——倍数、是否翻面、是否降维。

✏️ 习题 6.2 基础

用行列式判断 (2, 4) 与 (3, 6) 是否共线；再判断 (1, 2)、(3, 5) 是否线性无关。

查看答案与解析

det ⎡2 3; 4 6⎤ = 12 − 12 = 0 ⇒ 共线（相关）。det ⎡1 3; 2 5⎤ = 5 − 6 = −1 ≠ 0 ⇒ 线性无关。

解析：把向量竖着排进矩阵算 det：零 ⇔ 相关，非零 ⇔ 无关。第 2 章“解方程判相关”从此可以一步到位。注意判断相关性只看 det 是否为零，负号无妨。

✏️ 习题 6.3 基础

已知 det(A) = 3（A 为 2×2）。求 det(2A)、det(Aᵀ)、det(A⁵)。

查看答案与解析

det(2A) = 2²×3 = 12；det(Aᵀ) = 3；det(A⁵) = 3⁵ = 243。

解析：det(2A) 最易错——2A 是“每列都放大 2 倍”，面积按 2×2 = 4 倍走，不是 2 倍（3×3 矩阵则是 2³ = 8 倍）。det(A⁵) 用乘积性质连乘五次。

✏️ 习题 6.4 基础

求 det ⎡2 7 −3; 0 5 8; 0 0 4⎤。

查看答案与解析

上三角矩阵：det = 2×5×4 = 40。

解析：对角线以外的元素只产生“剪切”，不影响体积。这个性质是第 7 章消元法的好搭档：把矩阵消成三角形，det 顺手就出来了（只需记录行交换的变号与倍乘）。

✏️ 习题 6.5 进阶

取 A = ⎡2 0; 1 1⎤，B = ⎡1 3; 0 2⎤。分别计算 det(A)、det(B)、det(AB)，验证乘积性质，并用“缩放因子”语言复述一遍。

查看答案与解析

det(A) = 2，det(B) = 2。AB = ⎡2 6; 1 5⎤，det(AB) = 10 − 6 = 4 = 2×2 ✓。

解析：先做 B 面积翻倍，再做 A 又翻倍，合计 4 倍——倍数与先后顺序无关，所以尽管 AB ≠ BA，恒有 det(AB) = det(BA)。这是从行列式眼里看“乘法交换性”的一个有趣补偿。

✏️ 习题 6.6 进阶

三角形顶点为 (0, 0)、(4, 1)、(2, 3)。用行列式求其面积。

查看答案与解析

两边向量 (4, 1)、(2, 3) 张成的平行四边形面积 = |det ⎡4 2; 1 3⎤| = |12 − 2| = 10；三角形是它的一半，面积 = 5。

解析：|det|/2 是计算几何的标准三角形面积公式（顶点不在原点时先平移一个顶点到原点）。det 的符号还能告诉你三点是逆时针还是顺时针排列——多边形算法里非常常用。

✏️ 习题 6.7 挑战

(a) 用公式验证：交换 2×2 矩阵的两列，行列式变号。(b) 设 A 可逆（det(A) ≠ 0），利用 det(AB) = det(A)det(B) 证明 det(A⁻¹) = 1/det(A)。

查看答案与解析

(a) det ⎡b a; d c⎤ = bc − ad = −(ad − bc)。✓（几何：î、ĵ 落点互换 = 翻面。）

(b) A⁻¹A = I 两边取 det：det(A⁻¹)·det(A) = det(I) = 1，故 det(A⁻¹) = 1/det(A)。∎

解析：(b) 的几何读法：正变换把面积放大 k 倍，逆变换（倒放录像）必须缩回 1/k 倍。顺带注意：det(A) = 0 时 1/det(A) 无意义——再次印证“压扁的变换没有逆”。

✅ 本章要点

① det = 带符号的面积（体积）缩放因子，2×2 公式 ad − bc；② 负号 = 翻面，det = 0 = 压扁降维 = 列相关；③ det(AB) = detA·detB，三角矩阵取对角积，交换两列变号；④ |det|/2 可算三角形面积。
