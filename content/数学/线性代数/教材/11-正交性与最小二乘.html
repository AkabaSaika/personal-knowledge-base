第 11 章 · 正交性与最小二乘

为什么标准坐标系用起来那么顺手？因为坐标轴互相垂直——各方向互不干扰，坐标一人一个点积就能算。这一章把“垂直的好处”开发到极致：正交基、正交矩阵、Gram-Schmidt 流水线；然后用它兑现第 7 章的欠账——方程无解时，如何找出“最不错”的答案。数据科学的回归拟合，正是这道题。

🎯 学习目标

学完本章你能：① 用点积直接读出向量在标准正交基下的坐标；② 说出正交矩阵的判据 QᵀQ = I 及其“刚体变换”身份；③ 执行 Gram-Schmidt 把歪基扶正；④ 推导并使用正规方程 AᵀAx̂ = Aᵀb，完成最小二乘直线拟合。

标准正交基：自带快捷键的语言

一组基若两两垂直且长度全为 1，称标准正交基（记 q₁, q₂, …）。它的超能力：求坐标不用解方程组（第 9 章的日常），一个点积搞定。设 v = c₁q₁ + c₂q₂，两边点乘 q₁：交叉项 q₂·q₁ = 0 自动消失，|q₁|² = 1，剩下：

cᵢ = v · qᵢ        （坐标 = 投影，回想第 3 章习题 3.5）

“各分量互不干扰”正是垂直的全部含义——这也是傅里叶级数、JPEG 等一切“系数分解”技术选正交基的原因。

正交矩阵：保形状的变换

把标准正交基按列拼成 Q，则 QᵀQ 的第 (i, j) 元 = qᵢ·qⱼ = 0 或 1，即：

QᵀQ = I        ⇔        Q⁻¹ = Qᵀ      （求逆免费！）

这样的 Q 称正交矩阵。它保长度、保点积、保角度（证明见习题 11.6）——图形不变形，只被旋转或反射，故又称刚体变换；det(Q) = ±1（面积必须不变）。第 9 章习题 9.5 发现的“旋转基 P⁻¹ = Pᵀ”正是它的实例。

Gram-Schmidt：把歪基扶正

手里只有一组歪斜的基，想要正交的怎么办？逐个减掉投影（第 3 章的正交分解连环用）：

  1. 第一个方向直接归一化：q₁ = a₁ / |a₁|；
  2. 第二个向量减去它在 q₁ 上的影子，剩下的必与 q₁ 垂直，再归一化：u₂ = a₂ − (a₂·q₁)q₁，q₂ = u₂ / |u₂|；
  3. 更高维依此类推：每个新向量减去在所有已完工方向上的影子。

📘 例 1 · Gram-Schmidt 实算

把基 a₁ = (3, 1)、a₂ = (2, 2) 正交化。

解：|a₁| = √10，q₁ = (3, 1)/√10。投影系数：a₂·a₁ / |a₁|² = 8/10 = 0.8，故 u₂ = (2, 2) − 0.8(3, 1) = (−0.4, 1.2)。检验 (−0.4, 1.2)·(3, 1) = −1.2 + 1.2 = 0 ✓。归一化：q₂ = (−1, 3)/√10。所得 {q₁, q₂} 标准正交。

无解方程的最优答案：投影

第 7 章的判决：Ax = b 无解 ⇔ b 不在列空间 C(A) 里。现实数据几乎总是如此——三个以上带噪声的点很难恰好共线。放弃“精确解”，改问：哪个 x̂ 让 Ax̂ 与 b 的距离 |b − Ax̂| 最小？

几何答案一目了然：Ax̂ 只能在列空间里跑，离 b 最近的点就是 b 在 C(A) 上的投影；此时误差向量 b − Ax̂ 必垂直于整个列空间（影子的残差垂直于地面）。“垂直于每一列”翻译成矩阵语言 Aᵀ(b − Ax̂) = 0，整理得：

AᵀA x̂ = Aᵀ b        （正规方程 / normal equation）

无解的长方形方程组 Ax = b，两边左乘 Aᵀ 变成方形可解的方程组——这就是最小二乘法，“二乘”即“平方”：它最小化的是误差平方和。

用最小二乘拟合直线

给 n 个数据点 (xᵢ, yᵢ) 找最佳直线 y = kx + m：希望每个点满足 kxᵢ + m = yᵢ，写成矩阵是 A(k, m)ᵀ = y，其中 A 的第 i 行是 (xᵢ, 1)。点不共线时无解，套正规方程即得最优 k、m。亲手拖一拖：

拖动数据点，直线与虚线（残差）实时更新

💡 两个实验

① 把某个点竖直拖远变成“离群点”：直线被明显拽偏——平方惩罚放大了大误差，最小二乘对离群点敏感（统计学为此发明了稳健回归）；② 把所有点拖到近似一条线上：残差虚线几乎消失，误差平方和趋近 0——“有解”是“最小二乘”的特例。

📘 例 2 · 手算一次拟合

用最小二乘给三个点 (0, 1)、(1, 3)、(2, 4) 拟合直线 y = kx + m。

解：A = ⎡0 1; 1 1; 2 1⎤，y = (1, 3, 4)。AᵀA = ⎡0²+1²+2², 0+1+2; 0+1+2, 3⎤ = ⎡5 3; 3 3⎤，Aᵀy = (0·1+1·3+2·4, 1+3+4) = (11, 8)。解 ⎡5 3; 3 3⎤(k, m) = (11, 8)：相减得 2k = 3，k = 1.5；m = (8 − 4.5)/3 = 7/6 ≈ 1.17。最佳直线 y = 1.5x + 7/6。三点残差 (−1/6, 1/3, −1/6)，和为零且平方和已是全体直线中最小。

习题

✏️ 习题 11.1 基础

验证 q₁ = (0.6, 0.8)、q₂ = (−0.8, 0.6) 是标准正交基，并用点积求 v = (2, 1) 在该基下的坐标。

查看答案与解析

|q₁| = |q₂| = 1，q₁·q₂ = −0.48 + 0.48 = 0 ✓。坐标：c₁ = v·q₁ = 1.2 + 0.8 = 2；c₂ = v·q₂ = −1.6 + 0.6 = −1。即 v = 2q₁ − q₂（可展开验算）。

解析：对比第 9 章“歪基要解方程组”，正交基两个点积完事——这就是“快捷键”的含金量。

✏️ 习题 11.2 基础

Q = ⎡0.6 −0.8; 0.8 0.6⎤。验证 QᵀQ = I，写出 Q⁻¹，并说出 Q 的几何身份。

查看答案与解析

QᵀQ：对角元 0.36+0.64 = 1，交叉元 −0.48+0.48 = 0 ⇒ I ✓。Q⁻¹ = Qᵀ = ⎡0.6 0.8; −0.8 0.6⎤。det(Q) = 0.36+0.64 = 1，且列是 (cosθ, sinθ) 形式：Q 是旋转（θ ≈ 53.1°，即 3-4-5 三角形的那个角）。

解析：det = +1 的正交矩阵是纯旋转，det = −1 的是反射。判别正交矩阵永远用 QᵀQ = I，比逐列验长度、验垂直更机械可靠。

✏️ 习题 11.3 基础

对基 a₁ = (1, 1)、a₂ = (1, 0) 执行 Gram-Schmidt。

查看答案与解析

q₁ = (1, 1)/√2。投影系数 = (1, 0)·(1, 1)/2 = 1/2，u₂ = (1, 0) − ½(1, 1) = (½, −½)，归一化 q₂ = (1, −1)/√2。

解析：注意顺序有影响——先处理谁，谁就原方向保留。垂直检验 (1, 1)·(1, −1) = 0 一秒完成，Gram-Schmidt 每一步都自带验算点。

✏️ 习题 11.4 基础

求 b = (3, 4) 到直线 span((1, 1)) 的最近点 p，并验证残差 b − p 垂直于该直线。

查看答案与解析

投影：p = ((3, 4)·(1, 1) / 2)(1, 1) = (7/2)(1, 1) = (3.5, 3.5)。残差 (−0.5, 0.5)，与 (1, 1) 点积 = 0 ✓。最短距离 = |(−0.5, 0.5)| = √2/2。

解析：这是最小二乘的一维原型：C(A) 是一条直线时，正规方程退化成第 3 章的投影公式。看懂这个特例，正规方程只是它的“多列版”。

✏️ 习题 11.5 进阶

用正规方程给点 (0, 0)、(1, 1)、(2, 3) 拟合直线 y = kx + m。

查看答案与解析

A = ⎡0 1; 1 1; 2 1⎤，y = (0, 1, 3)。AᵀA = ⎡5 3; 3 3⎤，Aᵀy = (7, 4)。解得 2k = 3 ⇒ k = 1.5，m = (4 − 4.5)/3 = −1/6。直线 y = 1.5x − 1/6。

解析：残差 = (1/6, −1/3, 1/6)：与例 2 一样呈“小、大、小”且相加为零——残差和为零是正规方程第二行（m 的方程）的直接推论，可作快速验算。

✏️ 习题 11.6 进阶

证明正交矩阵保长度：|Qv| = |v| 对一切 v 成立。（提示：把模长平方写成 vᵀv。）

查看答案与解析

|Qv|² = (Qv)ᵀ(Qv) = vᵀQᵀQv = vᵀIv = |v|²。∎（用到第 5 章的 (AB)ᵀ = BᵀAᵀ。）

解析：同一套展开可证保点积：(Qu)·(Qv) = u·v，长度与夹角全保 ⇒ 刚体。反向也成立：保长度的线性变换必是正交矩阵——“QᵀQ = I”恰好是“不变形”的代数全权代表。

✏️ 习题 11.7 挑战

投影到列空间的矩阵为 P = A(AᵀA)⁻¹Aᵀ（A 列无关）。证明 P² = P，并解释这个等式的几何必然性。

查看答案与解析

P² = A(AᵀA)⁻¹AᵀA(AᵀA)⁻¹Aᵀ = A(AᵀA)⁻¹Aᵀ = P（下划线部分 = I）。∎

几何解释：P 把任何向量拍到列空间上；已经躺在列空间里的向量再拍一次不会动。“投影两次 = 投影一次”，故 P² = P。满足此式的矩阵统称幂等矩阵，投影是其几何原型。

解析：顺带一提，P 还满足 Pᵀ = P（对称）——第 12 章开幕的主角正是对称矩阵，而投影矩阵是它最亲切的实例：特征值只有 1（列空间方向，拍上去不动）和 0（垂直方向，拍没了）。

✅ 本章要点

① 标准正交基：坐标 = 点积，各分量互不干扰；② 正交矩阵 QᵀQ = I ⇔ Q⁻¹ = Qᵀ，保长保角 = 旋转/反射；③ Gram-Schmidt：逐个减影子再归一化；④ 无解时求最优：误差 ⊥ 列空间 ⇒ 正规方程 AᵀAx̂ = Aᵀb，直线拟合即其应用。
