第 9 章 · 基变换与坐标

结构篇开幕。一个向量是客观存在的“箭头”，而坐标 (3, 2) 只是它在某门“语言”（某组基）里的名字。换一组基，同一支箭头就换一个名字。这一章练习在语言之间自由翻译——它本身不难，却是打开特征值、对角化这些重头戏的钥匙：很多难题换一门语言描述，就变成了简单题。

🎯 学习目标

学完本章你能：① 解释“坐标 = 基下的组合系数”；② 用换基矩阵 P 在新旧坐标间双向翻译（并且不搞反方向）；③ 解释相似矩阵 P⁻¹AP 是“同一变换的另一种语言描述”；④ 说出换基的动机——挑一门让问题变简单的语言。

坐标其实是一份“配方”

写下 v = (3, 2) 时，我们默认了一份约定：v = 3î + 2ĵ——坐标是标准基的组合系数。但第 2 章说过，任何两个不共线的向量 b₁、b₂ 都能当基：同一个 v 总能唯一写成 c₁b₁ + c₂b₂，于是 (c₁, c₂) 就是 v 在新基下的坐标。箭头没变，变的只是记账方式。

🧪 拖一拖：同一个点，两套坐标
拖动基向量 b₁、b₂ 和红点 v，对照两套坐标

💡 两个实验

① 只拖红点 v：两套坐标一起变，但各自按各自的网格记账；② 只拖基向量：红点纹丝不动，新坐标却在变——“改语言不改事实”。试着把 b₂ 拖到与 b₁ 共线：网格塌成一族平行线，坐标失效（这就是基必须线性无关的原因）。

换基矩阵：两个方向的翻译

把新基向量（用标准语言写下的）按列拼成矩阵 P = [b₁ b₂]，翻译就是矩阵乘法：

v_标准 = P · v_新       （新坐标 → 标准坐标：按配方组合，自然方向）
v_新   = P⁻¹ · v_标准    （标准坐标 → 新坐标：反向翻译要用逆）

⚠️ 方向最容易搞反

记忆锚点：P 的列本身就是用标准语言写的新基向量，所以 P 吃“新语言”吐“标准语言”。拿基向量自查一次即可校准：b₁ 在新基下的坐标显然是 (1, 0)，而 P·(1, 0) = 第一列 = b₁ 的标准坐标 ✓。方向反了这个检验立刻穿帮。

变换也要翻译：相似矩阵

矩阵 A 描述一个变换时，用的也是标准语言（它的列是 î、ĵ 的去向）。同一个变换在新基下的矩阵是什么？走一条“翻译三部曲”：拿到新坐标 → 先翻译成标准语言（乘 P）→ 做变换（乘 A）→ 再翻译回新语言（乘 P⁻¹）：

A_新 = P⁻¹ A P        （读法：右起——翻进来、变换、翻回去）

形如 P⁻¹AP 的矩阵与 A 互称相似矩阵：同一个几何动作、不同语言的两份描述。既然动作相同，那些不依赖语言的“客观量”必然一致——比如行列式（面积缩放倍数不因记账方式而变，证明见习题 9.7）。

📘 一次令人心动的换基

取 A = ⎡3 1; 0 2⎤，新基 b₁ = (1, 0)、b₂ = (−1, 1)，即 P = ⎡1 −1; 0 1⎤（det = 1，P⁻¹ = ⎡1 1; 0 1⎤）。计算：AP = ⎡3 −2; 0 2⎤，P⁻¹AP = ⎡1 1; 0 1⎤⎡3 −2; 0 2⎤ = ⎡3 0; 0 2⎤——对角矩阵！在这门语言里，“复杂”的 A 露出真身：沿 b₁ 拉伸 3 倍、沿 b₂ 拉伸 2 倍，仅此而已。

为什么偏偏这组基有此奇效？验证一下：Ab₁ = (3, 0) = 3b₁，Ab₂ = (−3+1, 2) = (−2, 2) = 2b₂——这两个方向被 A 变换后方向不变，只是伸缩。这样的方向如何系统地找出来？正是下一章的全部内容。

为什么要换基

  • 让变换变简单：对角矩阵下，求幂、解方程都是逐轴独立的小学算术（第 10 章展开）。
  • 让数据变简单：JPEG 把图像换到“频率基”后大量系数接近零，砍掉就是压缩；PCA 把数据换到“主方向基”实现降维（第 12 章）。
  • 让物理变简单：斜面问题选“沿斜面 + 垂直斜面”的基，受力分解一步到位。

一句话：基是视角，换基是选择对问题最友好的视角。

例题

📘 例 1 · 新 → 标准

新基 b₁ = (2, 1)、b₂ = (−1, 1)。某向量在新基下的坐标为 (2, 1)，求它的标准坐标。

解：按配方组合：2·(2, 1) + 1·(−1, 1) = (3, 3)。矩阵写法：P = ⎡2 −1; 1 1⎤，P·(2, 1) = (3, 3)，一致。

📘 例 2 · 标准 → 新

沿用例 1 的基，求标准坐标 (5, 1) 在新基下的坐标。

解：解 c₁(2, 1) + c₂(−1, 1) = (5, 1)：由 2c₁ − c₂ = 5 与 c₁ + c₂ = 1 相加得 3c₁ = 6，c₁ = 2，c₂ = −1。新坐标 (2, −1)。也可先算 P⁻¹ = ⅓⎡1 1; −1 2⎤ 再乘——反向翻译=解方程组=乘逆矩阵，三位一体（第 7、8 章在此会师）。

习题

✏️ 习题 9.1 基础

新基 b₁ = (1, 2)、b₂ = (3, 1)。向量 w 的新基坐标为 (2, −1)，求其标准坐标。

查看答案与解析

2(1, 2) − 1(3, 1) = (−1, 3)。

解析：新 → 标准永远是“无脑组合”，不需要解方程也不需要逆矩阵——先分清方向再动笔。

✏️ 习题 9.2 基础

沿用 9.1 的基，求标准坐标 (5, 5) 在新基下的坐标。

查看答案与解析

解 c₁(1, 2) + c₂(3, 1) = (5, 5)：c₁ + 3c₂ = 5，2c₁ + c₂ = 5。解得 c₁ = 2，c₂ = 1，新坐标 (2, 1)。

解析：验算走反方向：2(1, 2) + 1(3, 1) = (5, 5) ✓。一来一回互为检验，是换基计算的标准自查动作。

✏️ 习题 9.3 基础

下列向量组能否作平面的基？(a) (2, 1) 与 (4, 2)；(b) (1, 1) 与 (1, −1)；(c) (0, 3) 与 (2, 0)。

查看答案与解析

(a) det = 4 − 4 = 0，共线，不能。(b) det = −2 ≠ 0，能。(c) det = −6 ≠ 0，能。

解析：基的资格审查 = 一个行列式。演示里把 b₂ 拖到与 b₁ 共线时坐标失效，就是 (a) 的下场——P 不可逆，反向翻译 P⁻¹ 不存在。

✏️ 习题 9.4 基础

基为 b₁ = (1, 2)、b₂ = (0, 1)。写出 P 与 P⁻¹，并把标准坐标 (3, 8) 翻译成新坐标。

查看答案与解析

P = ⎡1 0; 2 1⎤，det = 1，P⁻¹ = ⎡1 0; −2 1⎤。新坐标 = P⁻¹(3, 8) = (3, 2)。

解析：验算：3(1, 2) + 2(0, 1) = (3, 8) ✓。det = 1 的基翻译时不产生分数，手算最舒服。

✏️ 习题 9.5 进阶

新基取旋转 45° 后的标准基：b₁ = (√2/2, √2/2)，b₂ = (−√2/2, √2/2)。求标准坐标 (1, 0) 的新坐标，并观察 P⁻¹ 与 Pᵀ 的关系。

查看答案与解析

P 就是旋转矩阵 R(45°)。P⁻¹ = R(−45°) = ⎡√2/2 √2/2; −√2/2 √2/2⎤ = Pᵀ！新坐标 = Pᵀ(1, 0) = (√2/2, −√2/2)。

解析：几何上显然：旋转的逆就是反向旋转。代数上这不是巧合——基向量标准正交时恒有 P⁻¹ = Pᵀ，反向翻译从“解方程”降价为“做点积”（新坐标第 i 个分量 = v·bᵢ）。这类“黄金基”是第 11 章的主角。

✏️ 习题 9.6 进阶

A = ⎡2 1; 1 2⎤，P = ⎡1 −1; 1 1⎤。计算 P⁻¹AP，并解读结果。

查看答案与解析

det(P) = 2，P⁻¹ = ½⎡1 1; −1 1⎤。AP = ⎡3 −1; 3 1⎤，P⁻¹AP = ½⎡6 0; 0 2⎤ = ⎡3 0; 0 1⎤。

解析：又是对角！在基 {(1, 1), (1, −1)} 眼中，A 只是“沿 (1, 1) 拉伸 3 倍、沿 (1, −1) 原地不动”。验证：A(1, 1) = (3, 3) = 3(1, 1)，A(1, −1) = (1, −1) ✓。注意这两个方向互相垂直——对称矩阵的特征方向总是如此，伏笔埋到第 12 章。

✏️ 习题 9.7 挑战

证明相似矩阵行列式相等：det(P⁻¹AP) = det(A)。再用一句几何语言解释为什么这是“必然的”。

查看答案与解析

由乘积性质与 det(P⁻¹) = 1/det(P)（第 6 章习题 6.7）：det(P⁻¹AP) = det(P⁻¹)·det(A)·det(P) = (1/det P)·det(A)·det(P) = det(A)。∎

几何解释：行列式是“面积缩放倍数”，这是变换本身的客观属性；相似矩阵只是同一变换换了记账语言，客观属性当然不变。（同样对语言免疫的还有特征值与迹——下一章见。）

解析：注意 det(P) 在算式中一约而空：翻译工作“进来一次、出去一次”，对面积的影响恰好抵消。这类“共轭不变量”的论证模式在数学中随处可见。

✅ 本章要点

① 坐标 = 基下的组合系数，箭头客观、名字随基而变；② P 列 = 新基向量（标准语言书写），v_标准 = P·v_新，反向用 P⁻¹；③ 变换的翻译：A_新 = P⁻¹AP，相似矩阵 = 同一动作的不同描述，det 等客观量不变；④ 换基的意义：挑对语言，难题变简单题。
