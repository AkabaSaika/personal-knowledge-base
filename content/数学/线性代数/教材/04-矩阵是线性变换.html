第 4 章 · 矩阵是线性变换

矩阵篇开幕。从这一章起，请把“矩阵是一张数表”的印象暂时放到一边——我们要换一副眼镜：矩阵是一台机器，吃进一个向量，吐出一个新向量；它作用于整个平面，把网格整体搬动、旋转、拉伸。这副眼镜戴上之后，矩阵乘法、行列式、特征值……后面每一章都会突然变得“看得见”。

🎯 学习目标

学完本章你能：① 说出线性变换的几何特征与代数定义；② 解释“矩阵的列 = 基向量的去向”，并据此在矩阵和几何效果之间双向翻译；③ 熟练计算矩阵乘向量，并用“列的线性组合”解读它；④ 写出旋转、缩放、剪切、反射的矩阵。

换一副眼镜：函数，但吃向量

中学的函数 f(x) 把一个数变成另一个数。变换无非是“吃向量的函数”：输入平面上一个向量（或点），输出另一个向量。修图软件把整张照片拉宽、游戏引擎旋转镜头里的世界、把数据整体标准化——都是变换。线性代数关心其中最规矩的一类：线性变换。

几何上，线性变换有两个招牌特征：网格线变换后仍是平行等距的直线（不弯曲、不扭曲），且原点不动。代数上，这等价于它尊重向量的两种基本运算：

T(u + v) = T(u) + T(v)        （先加再变 = 先变再加）
T(k·u)  = k·T(u)             （先缩放再变 = 先变再缩放）

一句话：线性变换保持线性组合——T(au + bv) = aT(u) + bT(v)。这个看似平淡的性质，马上会爆发出惊人的力量。

两根柱子撑起整个变换

回忆第 2 章：平面上任何向量都能唯一写成标准基的组合，v = (x, y) = xî + yĵ。现在对它施加线性变换 T，用“保持线性组合”展开：

T(v) = T(x·î + y·ĵ) = x·T(î) + y·T(ĵ)

看清楚这句话的分量：只要知道两个基向量变到哪里（T(î) 和 T(ĵ)），任何向量的去向就完全确定了——照着同样的系数重新组合即可。整个平面无穷多个点的变换规则，被压缩成两个向量的信息。

把这两个“去向”竖着并排写成一个 2×2 数表，就是矩阵：

       ⎡ a   b ⎤          第 1 列 (a, c) = î 的去向
  A  =  ⎢       ⎥
       ⎣ c   d ⎦          第 2 列 (b, d) = ĵ 的去向

💡 全书最重要的一句话

矩阵的列，就是基向量变换后的落点。拿到任何矩阵，先竖着读它的两列，在脑中把 î、ĵ 挪到那两个位置，网格随之变形——你就“看见”了这个矩阵。

于是矩阵乘向量的公式，其实就是“按系数重新组合两列”：

⎡ a  b ⎤ ⎡ x ⎤     ⎡ a ⎤      ⎡ b ⎤    ⎡ ax + by ⎤
⎢      ⎥ ⎢   ⎥ = x·⎢   ⎥ + y·⎢   ⎥ = ⎢         ⎥
⎣ c  d ⎦ ⎣ y ⎦     ⎣ c ⎦      ⎣ d ⎦    ⎣ cx + dy ⎦

“行乘列”的机械口诀与“列的线性组合”的几何读法算出的结果相同——计算时用前者，理解时用后者。

⚠️ 最后一个按钮出事了

“压成直线!”让两列（两个落点）挤到同一方向——整个平面被拍扁成一条直线。二维的信息被压掉了一维，而且再也复原不回去。这种“降维事故”正是第 6 章行列式（det = 0）与第 8 章零空间的主角，先留个印象。

例题

📘 例 1 · 两种读法算同一件事

设 A 的列为 (2, 0) 与 (1, 3)，求 A 作用在 v = (1, 1) 上的结果。

解：列组合读法：Av = 1·(2, 0) + 1·(1, 3) = (3, 3)。行乘列读法：(2×1 + 1×1, 0×1 + 3×1) = (3, 3)，一致。几何含义：v 原本是“î 走一步、ĵ 走一步”，变换后照方抓药——“新 î 走一步、新 ĵ 走一步”。

📘 例 2 · 由几何效果反写矩阵

写出“逆时针旋转 90°”的矩阵，并求点 (3, 2) 旋转后的位置。

解：î = (1, 0) 旋转后落到 (0, 1)；ĵ = (0, 1) 落到 (−1, 0)。两列一拼：A = [(0, 1), (−1, 0)] 即上图第一个矩阵。作用于 (3, 2)：3·(0, 1) + 2·(−1, 0) = (−2, 3)。可在坐标纸上验证。

📘 例 3 · 不是谁都配叫“线性”

判断平移 T(x, y) = (x + 1, y) 是否线性变换。

解：不是。最快的检验：线性变换必须保持原点不动（T(0) = 0·T(0) = 0），而平移把原点挪到了 (1, 0)。也可验证 T(2u) ≠ 2T(u)。平移虽简单却不线性——这正是计算机图形学引入“齐次坐标”的原因（此处按下不表）。

习题

✏️ 习题 4.1 基础

A 的列为 (1, 2) 与 (3, −1)。分别用“列的线性组合”和“行乘列”计算 A(2, 1) 与 A(−1, 3)，确认两种算法结果一致。

查看答案与解析

A(2, 1) = 2(1, 2) + 1(3, −1) = (5, 3)；A(−1, 3) = −1(1, 2) + 3(3, −1) = (8, −5)。行乘列结果相同。

解析：建议在练习阶段坚持先用列组合读法算一遍——它慢一点，但每算一次都在强化“矩阵的列是去向”的直觉；熟练后行乘列自然接管。

✏️ 习题 4.2 基础

某线性变换把 î 变到 (2, 1)，把 ĵ 变到 (0, −1)。写出它的矩阵，并求 (1, 2) 的像。

查看答案与解析

矩阵两列即两个去向：A = ⎡2 0; 1 −1⎤（第 1 列 (2,1)，第 2 列 (0,−1)）。像 = 1·(2, 1) + 2·(0, −1) = (2, −1)。

解析：这是“列 = 去向”的正向使用。注意去向 (2, 1) 是竖着放进第一列的——初学最常见的错误是把它横着写成第一行。

✏️ 习题 4.3 基础

写出下列变换的矩阵：(a) 沿 x 轴反射（上下翻转）；(b) 所有向量放大为 3 倍；(c) 水平方向拉伸 2 倍、竖直方向不变。分别求 (1, 2) 的像。

查看答案与解析

(a) ⎡1 0; 0 −1⎤，(1, 2) ↦ (1, −2)；(b) ⎡3 0; 0 3⎤ = 3I，(1, 2) ↦ (3, 6)；(c) ⎡2 0; 0 1⎤，(1, 2) ↦ (2, 2)。

解析：三个都是对角矩阵——两个基向量各自沿自己的方向伸缩、互不打扰。对角矩阵是“最省心的变换”，第 10 章对角化的目标就是把一般矩阵改造成这种形态。

✏️ 习题 4.4 基础

剪切矩阵 S = ⎡1 1; 0 1⎤。求 (0, 1)、(1, 1)、(2, 3) 的像，并用一句话描述 S 的几何效果。

查看答案与解析

(0, 1) ↦ (1, 1)；(1, 1) ↦ (2, 1)；(2, 3) ↦ (5, 3)。

解析：S 保持 î 不动，把 ĵ 斜推到 (1, 1)：每个点的 y 坐标不变，x 坐标被推移了 y 的量——像一摞扑克牌被推歪。注意所有像的 y 分量都没变，这类“有方向不动”的现象将在第 10 章（特征向量）成为主角。

✏️ 习题 4.5 进阶

判断下列变换是否线性：(a) T(x, y) = (2x − y, x + 3y)；(b) T(x, y) = (x², y)；(c) T(x, y) = (x + 1, 2y)。

查看答案与解析

(a) 线性：每个输出分量都是输入的“常数×分量相加”，可写成矩阵 ⎡2 −1; 1 3⎤。(b) 不线性：T(2, 0) = (4, 0) ≠ 2·T(1, 0) = (2, 0)，平方破坏了数乘。(c) 不线性：T(0, 0) = (1, 0) ≠ (0, 0)，原点被挪动。

解析：速判三板斧——①输出分量必须是输入分量的一次齐次式（无平方、无乘积、无常数项）；②原点必须不动；③存疑时用定义验证 T(u+v) 与 T(ku)。

✏️ 习题 4.6 进阶

用“列 = 基向量去向”推导旋转 θ = 60° 的矩阵（写出精确值），并求 (1, 0) 与 (0, 2) 的像。

查看答案与解析

cos60° = 1/2，sin60° = √3/2。R(60°) = ⎡1/2 −√3/2; √3/2 1/2⎤。(1, 0) ↦ (1/2, √3/2)（就是第一列）；(0, 2) ↦ 2·(−√3/2, 1/2) = (−√3, 1)。

解析：“求 (1, 0) 的像”不用任何计算——它就是矩阵第一列本身。反过来这也是检验旋转矩阵是否写对的最快方法：第一列应落在角度 θ 的单位圆位置上。

✏️ 习题 4.7 挑战

证明：线性变换 T 把任何直线映成直线或一个点；特别地，过原点的直线映成过原点的直线或原点本身。提示：直线可写成 { p + td : t ∈ ℝ }。

查看答案与解析

直线上的点为 p + td（d ≠ 0 是方向向量）。由线性：T(p + td) = T(p) + t·T(d)。若 T(d) ≠ 0，这是过 T(p)、方向 T(d) 的直线；若 T(d) = 0，所有点都映到同一点 T(p)。过原点直线取 p = 0，而 T(0) = 0，故像仍过原点。∎

解析：这就是“网格线变换后仍是直线”的严格版本——本章开头的几何招牌特征，两行代数即证。注意 T(d) = 0 的退化情形恰是“压成直线/压成点”事故的局部版本：某个方向被整个吞进原点，这个方向的集合就是第 8 章的零空间。

✅ 本章要点

① 线性变换 = 保持线性组合的变换，几何上网格平行等距、原点不动；② 矩阵的列 = 基向量的去向，两列信息决定全平面；③ Av = 按 v 的坐标组合 A 的列；④ 旋转/缩放/剪切/反射各有标准矩阵，对角矩阵 = 各轴独立伸缩。
