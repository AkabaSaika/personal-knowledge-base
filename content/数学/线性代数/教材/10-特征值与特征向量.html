第 10 章 · 特征值与特征向量

变换把大多数向量又转又拉，但总有一些“天选方向”：变换之后方向不变，只是伸缩。这些方向叫特征向量，伸缩倍数叫特征值——它们是变换的骨架。摸清骨架，矩阵的百次幂可以口算，斐波那契有了通项公式，Google 靠它给网页排序。这是线性代数最著名的一章。

🎯 学习目标

学完本章你能：① 用几何语言解释 Av = λv；② 通过特征方程 det(A − λI) = 0 求特征值与特征向量；③ 完成对角化 A = PDP⁻¹ 并用它快速计算 Aⁿ；④ 说出斐波那契通项与 PageRank 背后的特征值思想。

寻找“不弯折的方向”

回忆第 4 章的剪切 ⎡1 1; 0 1⎤：所有向量都被推歪了——除了 x 轴上的向量，纹丝不动。再看第 9 章的 ⎡3 1; 0 2⎤：方向 (1, 0) 被拉伸 3 倍、方向 (−1, 1) 被拉伸 2 倍，都没有偏转。正式定义：

A v = λ v      （v ≠ 0）
v：特征向量（方向不变的向量）    λ：特征值（该方向的伸缩倍数）

λ 可以为负（方向调头、仍在同一条直线上）、可以为 0（该方向被压进原点——零空间！）。注意特征向量成“族”出现：v 是，2v、−v 也是，真正要找的是特征方向（一条过原点的直线）。先动手找找看：

🧪 拖一拖：绕一圈，找出方向不变的“天选向量”

💡 拖出三个结论

① 对称矩阵：慢慢转一圈，会在两个互相垂直的方向上撞见金色高亮（λ = 3 和 λ = 1）；② 剪切：只有 x 轴一个特征方向（λ = 1）；③ 旋转 90°：转遍一圈也找不到——旋转没有实特征方向（每个向量都被转走了）。

系统求解：特征方程

把定义移项：Av = λv ⇔ (A − λI)v = 0。这要求矩阵 A − λI 有非零的零空间成员，即 A − λI 必须“压扁”——第 6 章的判据立刻接管：

det(A − λI) = 0        （特征方程）

对 2×2 矩阵这是一个关于 λ 的二次方程（展开得 λ² − (a+d)λ + det(A) = 0）。流程两步走：解特征方程得 λ → 对每个 λ 解 (A − λI)v = 0 得方向。完整示范：

📘 例 1 · 全流程

求 A = ⎡2 1; 1 2⎤ 的特征值与特征向量。

第一步：det(A − λI) = (2−λ)² − 1 = 0 ⇒ 2 − λ = ±1 ⇒ λ₁ = 3，λ₂ = 1。

第二步：λ = 3 时，A − 3I = ⎡−1 1; 1 −1⎤，解 −x + y = 0 得方向 (1, 1)；λ = 1 时，A − I = ⎡1 1; 1 1⎤，解 x + y = 0 得方向 (1, −1)。

验算：A(1, 1) = (3, 3) = 3(1, 1) ✓；A(1, −1) = (1, −1) ✓。与演示中金色方向一致。注意 (A − λI) 此时必然行相关（det 为零本就是这么要求的）——解方程时两行给出同一条件，是正常现象而非算错。

三类速判，考试与工程里高频使用：

  • 三角/对角矩阵：特征值就是对角线元素（det(A − λI) 直接是对角连乘）。
  • λ = 0 ⇔ det(A) = 0：有方向被压进原点 ⇔ 矩阵奇异。
  • 旋转矩阵：特征方程 λ² + 1 = 0 无实根——几何直觉“没有方向不被转走”的代数印证。

对角化：换到特征基去

若 A 有两个独立的特征方向 v₁、v₂（伸缩倍数 λ₁、λ₂），拿它们当基（第 9 章！），P = [v₁ v₂]，则在这门语言里 A 只是“各轴独立伸缩”：

P⁻¹AP = D = ⎡λ₁  0⎤        等价地  A = P D P⁻¹
             ⎣0  λ₂⎦

这就是对角化。它最立竿见影的超能力是求幂——中间的 P⁻¹P 成对湮灭：

Aⁿ = (PDP⁻¹)(PDP⁻¹)⋯(PDP⁻¹) = P Dⁿ P⁻¹ = P ⎡λ₁ⁿ  0 ⎤ P⁻¹
                                              ⎣0   λ₂ⁿ⎦

百次幂从一百次矩阵乘法变成两个数各自求幂。几何读法：把输入翻译到特征基（P⁻¹），沿骨架各自伸缩 n 次（Dⁿ），再翻译回来（P）。

📘 例 2 · 用对角化求 A⁵

沿用例 1 的 A = ⎡2 1; 1 2⎤，求 A⁵。

解：P = ⎡1 1; 1 −1⎤，D = diag(3, 1)，P⁻¹ = ½⎡1 1; 1 −1⎤。A⁵ = P·diag(3⁵, 1)·P⁻¹ = P·diag(243, 1)·P⁻¹ = ½⎡243+1, 243−1; 243−1, 243+1⎤ = ⎡122 121; 121 122⎤。手乘五次矩阵？没人愿意。

⚠️ 不是人人可对角化

剪切 ⎡1 1; 0 1⎤ 只有一个特征方向，凑不齐一组基——不可对角化。特征值互不相同时必可对角化；出现重复特征值时要具体检查方向够不够数。

应用一瞥：特征值统治的世界

  • 斐波那契通项：数列 1, 1, 2, 3, 5, 8… 的递推可写成乘矩阵 F = ⎡1 1; 1 0⎤，第 n 项即 Fⁿ 的事。F 的特征值是黄金比例 φ = (1+√5)/2 与 ψ = (1−√5)/2，对角化直接给出通项 F(n) = (φⁿ − ψⁿ)/√5——相邻两项之比趋于 φ 的秘密就在“|φ| > |ψ|，大特征值最终称王”（习题 10.8）。
  • PageRank：把网络写成巨大的链接转移矩阵，网页的重要性排名 = 该矩阵最大特征值对应的特征向量。计算不靠解特征方程，而靠“幂迭代”：随便取初始向量反复乘矩阵，大特征值方向的分量增长最快，最终胜出——与斐波那契同一个原理。
  • 稳定性与振动：微分方程组、桥梁振动模态、人口模型的长期命运，全部由特征值的大小/正负决定：|λ| > 1 增长，|λ| < 1 衰减，λ = 1 恰是“稳态”（习题 10.6）。

习题

✏️ 习题 10.1 基础

A = ⎡4 1; 2 3⎤。验证 (1, 1) 与 (1, −2) 都是 A 的特征向量，并求各自的特征值。

查看答案与解析

A(1, 1) = (5, 5) = 5(1, 1) ⇒ λ = 5；A(1, −2) = (4−2, 2−6) = (2, −4) = 2(1, −2) ⇒ λ = 2。

解析：“验证”比“求解”容易得多——乘一下看是否共线。校验环节永远优先用定义本身。

✏️ 习题 10.2 基础

不解特征方程，直接写出 ⎡3 7; 0 2⎤ 与 ⎡5 0; 0 −1⎤ 的特征值；再求前者的特征向量。

查看答案与解析

三角矩阵读对角线：前者 λ = 3, 2；后者 λ = 5, −1。前者方向：λ = 3 时解 ⎡0 7; 0 −1⎤v = 0 得 (1, 0)；λ = 2 时解 ⎡1 7; 0 0⎤v = 0 得 x = −7y，方向 (−7, 1)。

解析：对角矩阵的特征方向就是坐标轴本身；上三角矩阵保住了 x 轴这一个“显然方向”，另一个则要动手解。

✏️ 习题 10.3 基础

求 A = ⎡1 2; 2 1⎤ 的特征值与特征向量，并说明负特征值的几何含义。

查看答案与解析

特征方程 (1−λ)² − 4 = 0 ⇒ λ = 3, −1。λ = 3：方向 (1, 1)；λ = −1：解 ⎡2 2; 2 2⎤v = 0 得方向 (1, −1)。

解析：λ = −1 表示 (1, −1) 方向的向量被原样调头——仍在同一条直线上，所以合格。又一个对称矩阵、又一对垂直的特征方向，第 12 章将宣布这不是巧合。

✏️ 习题 10.4 基础

从几何和代数两个角度说明：旋转 90° 矩阵 ⎡0 −1; 1 0⎤ 没有实特征向量。

查看答案与解析

几何：每个非零向量都被转过 90°，不可能与自己共线。代数：det(A − λI) = λ² + 1 = 0 无实根（λ = ±i）。

解析：复数根 ±i 并非“无意义”——它们编码着“旋转 90°”这一事实本身（复平面上乘 i 恰是转 90°）。复特征值是通往更深理论的门，本教材在此止步、留个路标。

✏️ 习题 10.5 进阶

对角化习题 10.3 的 A = ⎡1 2; 2 1⎤，并写出 Aⁿ 的显式公式。

查看答案与解析

P = ⎡1 1; 1 −1⎤，D = diag(3, −1)，P⁻¹ = ½⎡1 1; 1 −1⎤。Aⁿ = P·diag(3ⁿ, (−1)ⁿ)·P⁻¹ = ½⎡3ⁿ+(−1)ⁿ, 3ⁿ−(−1)ⁿ; 3ⁿ−(−1)ⁿ, 3ⁿ+(−1)ⁿ⎤。

解析：抽查 n = 1：½⎡3−1, 3+1; …⎤ = ⎡1 2; 2 1⎤ ✓。注意 (−1)ⁿ 的振荡被 3ⁿ 迅速淹没——n 稍大时 Aⁿ ≈ (3ⁿ/2)⎡1 1; 1 1⎤，一切向量都被甩向主特征方向 (1, 1)。这就是幂迭代能找到主特征向量的原因。

✏️ 习题 10.6 进阶

城乡人口每年迁移：留城概率 0.9、进城概率 0.2，转移矩阵 M = ⎡0.9 0.2; 0.1 0.8⎤（列为“今年城/乡”，行是“明年城/乡”）。求 M 的特征值，并求人口比例的长期稳态。

查看答案与解析

特征方程：λ² − 1.7λ + 0.7 = 0 ⇒ λ = 1, 0.7。λ = 1 的特征向量：(M − I)v = 0 ⇒ −0.1x + 0.2y = 0 ⇒ x = 2y，方向 (2, 1)。归一化成比例：城 2/3、乡 1/3。

解析：λ = 1 的方向是“乘一年不变”的分布——稳态；另一特征值 0.7 < 1，其分量每年衰减 30%，无论初始分布如何终将消失。长期行为 = 主特征向量，这正是 PageRank 的数学核心（网页排名就是链接矩阵的稳态分布）。

✏️ 习题 10.7 挑战

对 2×2 矩阵证明：两特征值之和 = 迹（对角线之和 a + d），之积 = det(A)。

查看答案与解析

特征方程展开为 λ² − (a+d)λ + (ad − bc) = 0。由韦达定理：λ₁ + λ₂ = a + d = tr(A)，λ₁λ₂ = ad − bc = det(A)。∎

解析：两条即时妙用——①解题：先算 tr 与 det，特征值经常能心算凑出（如 tr = 4、det = 3 ⇒ λ = 1, 3）；②校验：解完特征方程用和与积回查。几何彩蛋：λ₁λ₂ = det 再自然不过——沿两条骨架分别伸缩 λ₁、λ₂ 倍，面积当然放大 λ₁λ₂ 倍。

✏️ 习题 10.8 挑战

斐波那契递推 F(n+1) = F(n) + F(n−1) 可写成 (F(n+1), F(n)) = M·(F(n), F(n−1))，M = ⎡1 1; 1 0⎤。(a) 求 M 的特征值；(b) 解释为何 F(n+1)/F(n) → φ（黄金比例）。

查看答案与解析

(a) 特征方程 λ² − λ − 1 = 0 ⇒ λ = (1 ± √5)/2，即 φ ≈ 1.618 与 ψ ≈ −0.618。

(b) 把初始向量按两个特征方向分解：(F(2), F(1)) = c₁v_φ + c₂v_ψ。乘 n 次 M：状态 = c₁φⁿv_φ + c₂ψⁿv_ψ。由 |ψ| < 1，第二项指数消亡，状态向量的方向趋于 v_φ，而沿 v_φ 每乘一次放大 φ 倍，故相邻项之比 → φ。∎

解析：整理成套路：递推 → 矩阵幂 → 特征分解 → 大特征值决定长期行为。同一套路通吃人口模型、马尔可夫链、幂迭代算法。顺带一提，把分解系数算全即得通项 F(n) = (φⁿ − ψⁿ)/√5——一个整数数列的通项里住着两个无理数，相减后无理部分恰好抵消。

✅ 本章要点

① Av = λv：特征向量方向不变、特征值是伸缩倍数；② 求解两步：det(A − λI) = 0 → 解 (A − λI)v = 0；③ 对角化 A = PDP⁻¹（特征向量当基），Aⁿ = PDⁿP⁻¹；④ tr = Σλ，det = Πλ；⑤ 长期行为由最大特征值统治（斐波那契、PageRank、稳态）。
