第 8 章 · 逆矩阵、列空间、零空间与秩

矩阵篇收官。四个新名词，其实是同一个问题的四个侧面：变换 A 丢掉信息了吗？没丢——可以倒放（逆矩阵）；丢了——丢到哪儿去了（零空间）、还剩多少（秩）、能到达哪里（列空间）。看懂这一章，Ax = b 何时有解、解长什么样，将获得终极答案。

🎯 学习目标

学完本章你能：① 解释逆矩阵的几何意义，用公式求 2×2 逆并解方程；② 求出矩阵的列空间与零空间，并说出各自的几何身份；③ 用消元求秩，运用秩-零化度定理；④ 给出 Ax = b 解的存在性与结构的完整判据。

逆矩阵：把录像倒着放

变换 A 把平面揉了一遍；逆变换 A⁻¹ 就是把这段录像倒放——把每个落点送回出发点。两段连播等于什么都没发生：

A⁻¹A = A A⁻¹ = I

并非所有变换都能倒放。第 4 章“压成直线!”那种把平面拍扁的变换，无数个点挤到了同一个落点，倒放时“该回到哪儿”无从回答——信息永久丢失。判据正是第 6 章备好的：

📐 可逆判据

A 可逆 ⇔ det(A) ≠ 0 ⇔ A 的列线性无关 ⇔ 变换没有压扁降维。此时 A 称为可逆矩阵（或非奇异矩阵）；det(A) = 0 的矩阵称奇异矩阵，没有逆。

2×2 的求逆公式（值得背下）：主对角线对调、副对角线变号、整体除以 det：

⎡a  b⎤⁻¹     1    ⎡ d  −b⎤
⎢    ⎥   = ————— · ⎢      ⎥
⎣c  d⎦     ad−bc  ⎣−c   a⎦

有了逆矩阵，Ax = b 形式上一步可解：x = A⁻¹b（两边左乘 A⁻¹）。更大的矩阵用“高斯–约当法”求逆：把 [A | I] 一路消元化成 [I | A⁻¹]——本质是对 I 重演一遍“解方程”的所有动作。实际数值计算中直接消元比先求逆更快更稳，逆矩阵更多是理论推导的语言。

列空间：变换能到达的地方

A 的列空间 C(A) = 所有列向量的张成 = 所有可能的输出 Ax 构成的集合。它直接回答方程组的存在性：

Ax = b 有解  ⇔  b ∈ C(A)      （b 是列的某个线性组合）

2×2 时只有两档：列无关 → C(A) 是整个平面，任何 b 都可达；列相关 → C(A) 缩成一条过原点的直线（或原点），直线外的 b 一概无解——第 7 章习题 7.7 的无解方程组正是这么造出来的。

零空间：被吞进原点的方向

A 的零空间 N(A) = 所有满足 Ax = 0 的输入集合——被变换压到原点的全部向量。求法：解齐次方程组 Ax = 0（消元 + 自由变量）。

可逆矩阵的零空间只有 {0}（谁也没被吞掉）；一旦发生压扁，整条直线的向量被吞进原点，零空间就“胖”起来。零空间的胖瘦决定解的唯一性：若 x₀ 是 Ax = b 的一个解，那么全部解恰为：

通解 = x₀（特解） + 零空间里的任意向量

理由一行：A(x₀ + n) = Ax₀ + An = b + 0 = b。第 7 章“特解 + 自由参数×方向”的通解结构，方向向量正是零空间的基。

秩：还剩几维

秩 rank(A) = 列空间的维数 = 变换后“幸存”的维数，计算上等于消元后主元的个数。2×2 满秩是 2（没压扁），秩 1 是压成线，秩 0 只剩原点（零矩阵）。被压掉的维数去哪了？进了零空间——这笔账恰好守恒：

📐 秩–零化度定理

对 m×n 矩阵 A：rank(A) + dim N(A) = n（输入维数）。读法：n 维输入中，rank 维幸存为输出，其余 dim N(A) 维被压进原点，一维都不多、一维都不少。

消元语言的对应版本你已在第 7 章用过：主元个数（= 秩）+ 自由变量个数（= 零空间维数）= 未知数个数。

A x = b 的终极判决表

条件存在性唯一性解集形状
b ∉ C(A)无解—空集
b ∈ C(A)，N(A) = {0}有解唯一一个点
b ∈ C(A)，N(A) ≠ {0}有解不唯一特解 + 零空间（点/线/面…平移）

方阵且可逆时永远落在第二行：任何 b 都有唯一解 A⁻¹b——这就是“可逆”在方程组语言里的全部含义。

例题

📘 例 1 · 求逆并解方程

A = ⎡2 1; 1 1⎤。求 A⁻¹，并解 Ax = (3, 2)。

解：det = 2 − 1 = 1 ≠ 0，可逆。套公式：A⁻¹ = ⎡1 −1; −1 2⎤。验证 AA⁻¹ = I ✓。x = A⁻¹(3, 2) = (3−2, −3+4) = (1, 1)。代回：A(1,1) = (3, 2) ✓。

📘 例 2 · 求列空间与零空间

A = ⎡1 2; 2 4⎤。求 C(A)、N(A) 与 rank(A)，并验证秩–零化度定理。

解：两列 (1, 2)、(2, 4) 共线 ⇒ C(A) = span((1, 2))，一条直线，rank = 1。零空间：解 x + 2y = 0（第二个方程是它的 2 倍），x = −2y，故 N(A) = span((−2, 1))，也是一条直线，维数 1。验证：1 + 1 = 2 = 列数 ✓。几何图景：方向 (−2, 1) 被压进原点，全平面坍缩到直线 span((1, 2)) 上。

📘 例 3 · 消元求秩

求 A = ⎡1 2 1; 2 4 0; 3 6 1⎤ 的秩。

解：R2 ← R2 − 2R1 → (0, 0, −2)；R3 ← R3 − 3R1 → (0, 0, −2)；R3 ← R3 − R2 → (0, 0, 0)。阶梯形有两个主元（第 1、3 列），rank = 2。顺带读出：第 2 列没有主元 ⇒ 零空间维数 = 3 − 2 = 1，且第 2 列 = 2×第 1 列的相关性清晰可见。

习题

✏️ 习题 8.1 基础

求 ⎡3 1; 5 2⎤ 的逆矩阵，并验证乘积为 I。

查看答案与解析

det = 6 − 5 = 1。A⁻¹ = ⎡2 −1; −5 3⎤。验证：⎡3 1; 5 2⎤⎡2 −1; −5 3⎤ = ⎡6−5, −3+3; 10−10, −5+6⎤ = I ✓。

解析：det = 1 时逆矩阵不产生分数，是出题人最爱。口诀复述一遍：主对调、副变号、除以 det。

✏️ 习题 8.2 基础

用逆矩阵解方程组：2x + y = 4；3x + 2y = 7。

查看答案与解析

A = ⎡2 1; 3 2⎤，det = 1，A⁻¹ = ⎡2 −1; −3 2⎤。x = A⁻¹(4, 7) = (8−7, −12+14) = (1, 2)。

解析：与高斯消元殊途同归。要解同一个 A、许多个不同 b 时，先求一次 A⁻¹ 再反复乘，才显出逆矩阵的效率优势。

✏️ 习题 8.3 基础

判断下列矩阵是否可逆：(a) ⎡1 2; 3 6⎤；(b) ⎡0 1; 1 0⎤；(c) ⎡2 0; 0 0⎤。对不可逆者，说出它把平面压成了什么。

查看答案与解析

(a) det = 0，不可逆：两列共线，平面压成直线 span((1, 3))。(b) det = −1 ≠ 0，可逆（交换 x、y 的反射，倒放就是再照一次镜子，B⁻¹ = B）。(c) det = 0，不可逆：第二列是零向量，ĵ 被吞进原点，平面压成 x 轴。

解析：判可逆 = 算 det = 检查列相关，三件事是一件事。

✏️ 习题 8.4 基础

求 A = ⎡1 3; 2 6⎤ 的零空间，并写出 Ax = (1, 2) 的通解（提示：先验证 (1, 0) 是一个特解）。

查看答案与解析

零空间：x + 3y = 0 ⇒ N(A) = span((−3, 1))。特解验证：A(1, 0) = (1, 2) ✓。通解 = (1, 0) + t·(−3, 1)，t ∈ ℝ——一条不过原点的直线。

解析：“特解 + 零空间”结构的最小实例。注意解集是零空间这条直线的平移：方向相同、错开一个特解。

✏️ 习题 8.5 进阶

求 A = ⎡1 1 2; 2 1 3; 3 2 5⎤ 的秩，并求零空间的一组基。

查看答案与解析

消元：R2 ← R2 − 2R1 → (0, −1, −1)；R3 ← R3 − 3R1 → (0, −1, −1)；R3 ← R3 − R2 → 全零行。两个主元 ⇒ rank = 2。零空间：由阶梯形 x + y + 2z = 0、−y − z = 0 得 y = −z，x = −y − 2z = −z。令 z = 1：基为 (−1, −1, 1)，dim N(A) = 1 = 3 − 2 ✓。

解析：验证可代回原矩阵：第 3 列 = 第 1 列 + 第 2 列，恰对应 (−1, −1, 1) 这个“配平系数”——零空间的每个向量都是列之间的一条“相关性记录”。

✏️ 习题 8.6 进阶

A 是 3×5 矩阵且 rank(A) = 2。(a) 零空间维数是多少？(b) 方程 Ax = b 有解时，解集是几维的？(c) 是否存在使方程无解的 b？

查看答案与解析

(a) 5 − 2 = 3 维。(b) 特解 + 3 维零空间 ⇒ 3 维（5 个未知数、2 个主元、3 个自由变量）。(c) 存在：C(A) 是 3 维空间中的 2 维平面，平面外的 b（“大多数”b）都无解。

解析：全程只用维数记账，不碰任何具体数字——这正是秩–零化度定理的威力：不解方程就能预知解集的“形状规格”。

✏️ 习题 8.7 挑战

设 A、B 均可逆。证明 (AB)⁻¹ = B⁻¹A⁻¹。

查看答案与解析

只需验证候选者与 AB 乘积为 I：(B⁻¹A⁻¹)(AB) = B⁻¹(A⁻¹A)B = B⁻¹IB = B⁻¹B = I；同理 (AB)(B⁻¹A⁻¹) = I。由逆的唯一性，(AB)⁻¹ = B⁻¹A⁻¹。∎

解析：又见“逆序原理”：AB 是先 B 后 A，倒放自然先撤 A、再撤 B——与 (AB)ᵀ = BᵀAᵀ（习题 5.7）同款结构。证明手法也值得记：要证某物是逆，乘一下看是否得 I，全程只用结合律。

✏️ 习题 8.8 挑战

证明：Ax = b 的任意两个解之差必属于零空间；并由此说明——若零空间只有 {0}，则解（若存在）必唯一。

查看答案与解析

设 Ax₁ = b 且 Ax₂ = b。相减：A(x₁ − x₂) = b − b = 0，故 x₁ − x₂ ∈ N(A)。若 N(A) = {0}，则 x₁ − x₂ = 0，即 x₁ = x₂，解唯一。∎

解析：两行代数把全章焊成一体——存在性归列空间管，唯一性归零空间管，互不越界。“判决表”三行的理论根基就在这道题里。

✅ 本章要点 · 矩阵篇完结

① 可逆 = 可倒放 ⇔ det ≠ 0 ⇔ 列无关；2×2 逆：主对调、副变号、除 det；② C(A) 管存在性（b 可达吗），N(A) 管唯一性（谁被压扁）；③ rank + dim N(A) = n，维数记账永远守恒；④ 通解 = 特解 + 零空间。
